POWER.SYS

Quand COMMAND attend une touche, le CPU tourne à vide. POWER détecte ces idles (INT 28, INT 2Fh, boucles clavier) et demande au BIOS APM d’endormir le processeur. SYSINIT l’appelle après les stubs HIGH (M072) pour qu’il accroche INT 2Fh correctement.

When COMMAND waits for a key, the CPU spins. POWER spots those idles (INT 28, INT 2Fh, keyboard loops) and asks the APM BIOS to sleep the processor. SYSINIT calls it after the HIGH stubs (M072) so it hooks INT 2Fh correctly.

Version standalone et version résidente fusionnées (juin 1991, MD). Même public que PRINT : les moments où DOS dit « je m’ennuie ».

Standalone and resident versions merged (June 1991, MD). Same audience as PRINT: the moments DOS says “I am bored”.

IntermédiaireIntermediate INT 1Ch · CPU_IDLE

M004 : compter le temps idle sur INT 1Ch (tic horloge). Un resume APM sans suspend préalable est ignoré (resumes multiples). M002 : l’accroche INT 14 (série) avait été commentée — l’impression ralentissait.

M004: count idle time on INT 1Ch (timer tick). An APM resume without a prior suspend is ignored (multiple resumes). M002: the INT 14 (serial) hook had been commented out — printing slowed down.

TechniqueTechnical M003 IOCTL retiré

Le reste du support IOCTL a été enlevé (29/8/91). POWER se commande surtout par la ligne POWER et par APM, plus par AH=44h.

APM

DécouverteDiscovery M001 août 1991

Advanced Power Management : le BIOS portable expose suspend / resume. POWER s’y branche. Sans APM, il reste le HLT.

Advanced Power Management: the laptop BIOS exposes suspend / resume. POWER hooks it. Without APM, HLT remains.

IntermédiaireIntermediate Do_APM_Enable_Disable

M005 : remettre d’aplomb les far calls dans le driver résident BIOS (near vs far). ROMDOS a forcé la séparation CODE / DATA / INIT.

M005: straighten far calls in the BIOS-resident driver (near vs far). ROMDOS forced the CODE / DATA / INIT split.

TechniqueTechnical Power_Init

SYSINIT (M072) : après les stubs DOS HIGH, pour que POWER accroche INT 2Fh une fois le multiplex en place — pas trop tôt.

HLT et V86

DécouverteDiscovery Endormir sans tout casser Sleep without breaking everything

HLT arrête le 8086 jusqu’à la prochaine IRQ. Sous EMM386 (V86), HLT est piégé : il faut demander au moniteur, pas exécuter l’opcode n’importe comment.

HLT stops the 8086 until the next IRQ. Under EMM386 (V86), HLT is trapped: you must ask the monitor, not just fire the opcode.

IntermédiaireIntermediate CheckV86

M004 / bug 2587 : ne tester V86 que pour le chemin HLT, pas pour OEM_IDLE ni APM_IDLE. Sinon on refuse à tort des idles APM sous EMM386.

M004 / bug 2587: only test V86 on the HLT path, not OEM_IDLE or APM_IDLE. Otherwise we wrongly refuse APM idles under EMM386.
