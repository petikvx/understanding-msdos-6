cmd/edlin — « LINE TEXT EDITOR », encore livré en 6

EDLIN

Avant QBasic EDIT, avant DOSSHELL, il y avait l’étoile. EDLIN AUTOEXEC.BAT, numéro de ligne, I insert, D delete, E end. Le dépôt le garde en DOS 4.00 : parseur, messages, DBCS, opens étendus — et les rustines de MZ de 1983.

Before QBasic EDIT, before DOSSHELL, there was the asterisk. EDLIN AUTOEXEC.BAT, line numbers, I insert, D delete, E end. The tree keeps it at DOS 4.00: parser, messages, DBCS, extended opens — and MZ’s 1983 patches.

* _

DécouverteDiscovery 1,20L · 5D · E

Le fichier tient en mémoire comme un tableau de lignes. On n’édite pas un écran : on adresse une ligne, on la remplace. n affiche, nI insère avant, n,mD efface, n,mRold$new remplace, W écrit une partie si la RAM déborde, A append le reste depuis le disque.

QBasic EDIT.COM est dans cmd/qbasic/ — hors saga OS. EDLIN reste l’éditeur que l’on peut encore relire entièrement en assembleur.

The file lives in memory as an array of lines. You do not edit a screen: you address a line and replace it. n lists, nI inserts before, n,mD deletes, n,mRold$new replaces, W writes a slice if RAM overflows, A appends the rest from disk.

QBasic EDIT.COM lives in cmd/qbasic/ — outside the OS saga. EDLIN is the editor you can still read entirely in assembler.

Vingt-deux mois de rustines

DécouverteDiscovery printf et les %

Rev. 3 (01-Feb-84) : « Repaired problem with using printf and having %'s as data. » Éditer un fichier qui contient un pour-cent cassait l’affichage. Leçon : ne pas réutiliser un formateur pour du texte libre.

Rev. 3 (01-Feb-84): “Repaired problem with using printf and having %'s as data.” Editing a file that contained a percent sign broke the display. Lesson: do not reuse a formatter for free text.

IntermédiaireIntermediate close before rename

À la sortie, EDLIN renomme l’ancien en .BAK et le tampon en fichier. MZ (30-Nov-83) : fermer l’entrée avant le rename — sous DOS 2, un handle ouvert tient le nom. « Out of space » sur la sortie devient fatal : mieux vaut garder le .BAK que produire un fichier tronqué qu’on croit bon.

On exit, EDLIN renames the old file to .BAK and the buffer to the filename. MZ (30-Nov-83): close the input before rename — under DOS 2 an open handle holds the name. “Out of space” on output becomes fatal: better keep the .BAK than write a truncated file that looks fine.

TechniqueTechnical read-only

Le message read-only (Rev. 13) interroge l’attribut avant d’ouvrir en écriture — le même bit que ATTRIB +R. Extended open (DOS 4) permet de demander l’accès sans course avec SHARE.

Mémoire pleine

DécouverteDiscovery W puis A

EDLIN ne mappe pas le fichier. Un AUTOEXEC tient. Un listing de 200 Ko, non. On écrit les premières lignes (W), on charge la suite (A). C’est l’ancêtre maladroit de l’éditeur virtuel.

EDLIN does not map the file. An AUTOEXEC fits. A 200 KB listing does not. You write the first lines (W), then append the rest (A). An awkward ancestor of a virtual editor.

IntermédiaireIntermediate vs DEBUG

DEBUG édite des octets et assemble. EDLIN édite du texte. Les deux sont des .EXE (EDLIN l’est devenu en 1983) et partagent le style « invite d’une lettre ».

DEBUG edits bytes and assembles. EDLIN edits text. Both are .EXE (EDLIN became one in 1983) and share the “one-letter prompt” style.
