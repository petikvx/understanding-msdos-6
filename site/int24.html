INT 24h

« Abort, Retry, Ignore, Fail ? » — le dialogue le plus célèbre de DOS. Ce n’est pas COMMAND.COM qui le décide d’abord : c’est le noyau (HardErr), sur AuxStack, au milieu d’un INT 21h.

“Abort, Retry, Ignore, Fail?” — DOS’s most famous prompt. COMMAND.COM is not first to decide: the kernel is (HardErr), on the AuxStack, in the middle of an INT 21h.

Quatre réponses

DécouverteDiscovery La disquette n’est pas prête The floppy is not ready

Retry : on réessaie. Ignore : on prétend que ça a marché (dangereux). Fail : l’appel rend une erreur (ce que les programmes « modernes » préfèrent). Abort : on tue le processus — Abort_Inner.

Retry: try again. Ignore: pretend it worked (dangerous). Fail: the call returns an error (what “modern” programs prefer). Abort: kill the process — Abort_Inner.

IntermédiaireIntermediate allowed_fail · INT 24 off

Chaque appel dit ce qui est permis (ALLOWED dans FAT : souvent fail seulement). L’open étendu peut couper INT 24 (INT_24_ERROR / EXT_OPEN_I24_OFF déjà vus dans $READ). M024 : pas de Fail/Ignore si on n’est pas vraiment dans un INT 24 (Ctrl-P / PrintScreen).

Each call says what is allowed (ALLOWED in FAT: often fail only). Extended open can turn INT 24 off (INT_24_ERROR / EXT_OPEN_I24_OFF already in $READ). M024: no Fail/Ignore if we are not really in INT 24 (Ctrl-P / PrintScreen).

TechniqueTechnical sf_busy = −1

Si INT 24 explose pendant OPEN, la SFT marquée −1 doit pouvoir être récupérée (page SFT). Nsp/Nss : un seul niveau de réentrance — CROSSTALK.

If INT 24 blows up during OPEN, the SFT marked −1 must be reclaimable (SFT page). Nsp/Nss: one re-entrancy level — CROSSTALK.

HardErr

DécouverteDiscovery Le noyau appelle le PSP The kernel calls the PSP

Le vecteur 24h du processus (sauvé dans le PSP, restauré à l’EXIT) reçoit AH=flags, DI=code. COMMAND.COM installe le sien dans rucode.asm : le texte français/anglais que l’on connaît.

The process’s 24h vector (saved in the PSP, restored at EXIT) gets AH=flags, DI=code. COMMAND.COM installs its own in rucode.asm: the familiar French/English text.

IntermédiaireIntermediate ErrorMode · GetExtendedError

Pendant INT 24, ErrorMode ≠ 0 : les appels AH=01–0Ch restent sur AuxStack. PRINT utilise AH=59h depuis ici — d’où sa pile dédiée (page INT 21h).

During INT 24, ErrorMode ≠ 0: AH=01–0Ch stay on AuxStack. PRINT uses AH=59h from here — hence its dedicated stack (INT 21h page).

TechniqueTechnical M011 NEC

Autrefois DOS mettait F202h dans les flags au retour (bit 1 toujours à 1). Les clones NEC 8086 utilisent ce bit « undocumented » : M011 préserve son état.

DOS used to store F202h in the flags on return (bit 1 always 1). NEC 8086 clones use that “undocumented” bit: M011 preserves its state.

Ctrl-C · INT 23h

DécouverteDiscovery L’autre interruption « humaine » The other “human” interrupt

CNTCHAND / INT 23h : l’utilisateur veut arrêter. COMMAND demande parfois confirmation en batch. DidCtrlC colore ensuite le code de sortie.

CNTCHAND / INT 23h: the user wants to stop. COMMAND sometimes asks for confirmation in a batch file. DidCtrlC then colours the exit code.

IntermédiaireIntermediate Break · AH=33h

Le flag Break (chemin court du dispatcher) dit si on teste Ctrl-C à chaque appel ou seulement sur CON. DSKSTATCHK le fait avant les appels disque.

The Break flag (dispatcher fast path) says whether we test Ctrl-C on every call or only on CON. DSKSTATCHK does it before disk calls.

TechniqueTechnical DIVOV

Le même fichier gère INT 0 (division par zéro) : DIVOV / RealDivOv. Tout ce qui « tue ou interrompt » un process passe par ici avant EXIT.
