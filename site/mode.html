cmd/mode/ — 16 fichiers .asm

MODE

Le couteau suisse IOCTL de la ligne de commande : 80/40 colonnes, baud du COM1, redirection LPT1→COM1, préparation d’une page de codes. Presque tout est un AH=44h habillé.

The command-line IOCTL Swiss army knife: 80/40 columns, COM1 baud, LPT1→COM1 redirect, code-page prep. Almost everything is a dressed-up AH=44h.

MODE CO80 · MODE 40

DécouverteDiscovery INT 10h

Change le mode texte. ANSI et GRAFTABL s’en soucient ensuite. Sans MODE, le BIOS reste dans le mode où le boot l’a laissé.

Changes the text mode. ANSI and GRAFTABL care afterwards. Without MODE, the BIOS stays in whatever the boot left.

IntermédiaireIntermediate lignes 25/43/50

MODE CON LINES=43 parle à EGA/VGA. /L d’ANSI peut ensuite figer ce nombre. Les deux se marchent sur les pieds si on les mélange.

MODE CON LINES=43 talks to EGA/VGA. ANSI’s /L can then freeze that count. The two step on each other if mixed carelessly.

Série et parallèle

DécouverteDiscovery MODE COM1:9600,N,8,1

IOCTL sur le handle AUX/COM. Interlnk et PRINT en dépendent. MODE LPT1=COM1 redirige le handle 4.

IOCTL on the AUX/COM handle. Interlnk and PRINT depend on it. MODE LPT1=COM1 redirects handle 4.

IntermédiaireIntermediate retry P/B/N

Busy, None, Error : que faire si l’imprimante n’est pas prête — avant même INT 24. PRINT a sa propre file par-dessus.

Busy, None, Error: what to do if the printer is not ready — even before INT 24. PRINT has its own queue on top.

TechniqueTechnical generic IOCTL

Les paramètres série (baud, parité) sont le generic IOCTL « send to device » de ioctl.inc, pas un appel BIOS direct — pour que le driver COM puisse être un substitut.

MODE CON CP

DécouverteDiscovery PREP · SEL

Prépare une page (charge le .CPI), puis SELECT. CHCP (COMMAND) parle à NLSFUNC ; MODE parle à DISPLAY.SYS. Les deux sont requis pour un AZERTY complet.

Prepare a page (load the .CPI), then SELECT. CHCP (COMMAND) talks to NLSFUNC; MODE talks to DISPLAY.SYS. Both are required for a complete AZERTY setup.

IntermédiaireIntermediate STATUS

MODE sans argument : état des devices. Utile pour voir si LPT1 est encore redirigé après un PRINT /T.

MODE with no argument: device status. Handy to see if LPT1 is still redirected after PRINT /T.
