cmd/help — DOS 5.0, MD 3-Oct-90

HELP

Pas un manuel. Un fichier texte DOSHELP.HLP pour la liste d’une ligne, et pour le détail : relancer la commande avec /?. Les éditeurs tiers n’ont qu’à ajouter une ligne au .HLP et implémenter /?.

Not a manual. A text file DOSHELP.HLP for the one-line list, and for the details: relaunch the command with /?. Third parties only add a line to the .HLP and implement /?.

Un fichier que tout le monde peut étendre

DécouverteDiscovery @ commentaires

Chaque ligne : nom en colonne 0, blancs, description. @ en première colonne = commentaire. CR-LF, 160 caractères max. HELP sans argument affiche la table. HELP DIR affiche l’entrée puis tente le détail.

Each line: name in column 0, whitespace, description. @ in the first column = comment. CR-LF, 160 characters max. HELP with no argument prints the table. HELP DIR prints the entry then tries for details.

IntermédiaireIntermediate internes vs externes

is_internal() compare à une table en dur — la sœur de COMTAB dans COMMAND :

BREAK CALL CD CHCP CHDIR CLS COPY CTTY DATE DEL DIR ECHO ERASE EXIT FOR GOTO IF LH LOADHIGH MD MKDIR PATH PAUSE PROMPT RD REM REN RENAME RMDIR SET SHIFT TIME TYPE VER VERIFY VOL

Un interne n’a pas d’EXE : HELP doit appeler COMMAND.COM /C DIR /?. Un externe : EXEC direct de DIR.COM… qui n’existe pas, donc XCOPY /?.

is_internal() compares against a hard-coded table — sister of COMTAB in COMMAND. An internal has no EXE: HELP must call COMMAND.COM /C DIR /?. An external: direct EXEC of the utility with /?.

La hauteur d’écran, encore

DécouverteDiscovery helper.asm

Même problème que MORE : 25, 43 ou 50 lignes ? D’abord IOCTL ANSI (440Ch / sous-fonction 037Fh), sinon 40:84h. Commentaire : « Code taken from MORE.COM ». La casse : « Code taken from FIND » — table de majuscules DOS, pas toupper C.

Same problem as MORE: 25, 43 or 50 lines? First ANSI IOCTL (440Ch / subfunction 037Fh), else 40:84h. Comment: “Code taken from MORE.COM”. Case: “Code taken from FIND” — DOS uppercase table, not C toupper.

IntermédiaireIntermediate stdout device ?

IOCTL bit DEVICE_BIT (80h) + STDOUT_BIT (02h) : si la sortie est un fichier, pas de pagination. HELP DIR > AIDE.TXT doit rester brut.

IOCTL bit DEVICE_BIT (80h) + STDOUT_BIT (02h): if output is a file, no paging. HELP DIR > AIDE.TXT must stay raw.

TechniqueTechnical spawn / process.h

C + un module ASM. process.h pour EXEC. Retour 2 = I/O, 3 = pas d’aide. Le /? que chaque utilitaire de cette saga a dû ajouter (DOSKEY 1.03, 17-Apr-90, c-PaulB) existe pour ce HELP-là.

CHOICE n’est pas dans l’arbre

DécouverteDiscovery DOS 6, ailleurs

CHOICE.COM (pause .BAT, /C:YN, errorlevel) est un classique MS-DOS 6. Dans ce dépôt : pas de cmd/choice/. Les seules occurrences de « choice » sont des invites FDISK ou des menus CONFIG.SYS. On le mentionne pour ne pas faire croire qu’il a été oublié — il n’a simplement pas été livré avec ces sources.

CHOICE.COM (BAT pause, /C:YN, errorlevel) is a classic MS-DOS 6 extra. In this tree: no cmd/choice/. The only “choice” hits are FDISK prompts or CONFIG.SYS menus. Mentioned so it is not mistaken for an omission — it simply did not ship with these sources.

IntermédiaireIntermediate PAUSE + IF ERRORLEVEL

Sans CHOICE, un .BAT fait PAUSE ou une boucle de FIND. COMMAND a déjà IF ERRORLEVEL — c’est le contrat que FIND, XCOPY, BACKUP, TREE honorent.

Without CHOICE, a BAT uses PAUSE or a FIND loop. COMMAND already has IF ERRORLEVEL — the contract FIND, XCOPY, BACKUP, TREE honour.
