Qu’est-ce qu’INT 21h What INT 21h is

Découverte Discovery Le guichet unique des programmes The programs’ single counter

Un programme DOS ne parle presque jamais au disque ou au clavier tout seul. Il met un numéro dans AH, éventuellement d’autres arguments dans les registres, et exécute INT 21h. Le processeur saute au vecteur 21h — l’entrée COMMAND de msdisp.asm. Au retour, AX (et parfois CF) dit si ça a marché.

A DOS program almost never talks to the disk or keyboard by itself. It puts a number in AH, maybe other arguments in the registers, and executes INT 21h. The CPU jumps to vector 21h — the COMMAND entry in msdisp.asm. On return, AX (and sometimes CF) says whether it worked.

Intermédiaire Intermediate Deux époques dans la même table Two eras in one table

AH=00–24 : héritage CP/M (console, FCB). AH=25+ : « extended functions » (vecteurs, date, puis le groupe XENIX : handles 3Ch–46h, mémoire 48h–4Ah, processus 4Bh–4Ch). MaxCall sépare les appels que CALL 5 (PSP) a encore le droit de faire.

AH=00–24: CP/M heritage (console, FCBs). AH=25+: “extended functions” (vectors, date, then the XENIX group: handles 3Ch–46h, memory 48h–4Ah, process 4Bh–4Ch). MaxCall is the last function CALL 5 (in the PSP) is still allowed to issue.

Technique Technical dispatch.txt

Le fichier dos/dispatch.txt est le plan de travail de 1983 : quelle routine dans quel .asm, quelles sections critiques (critDisk, critMem, critDevice, critNet). Les appels reçoivent tous les registres sauf CS:IP et SS:SP — d’où l’absence de lecture de la pile utilisateur dans $OPEN ou $ALLOC.

dos/dispatch.txt is the 1983 work plan: which routine in which .asm, which critical sections (critDisk, critMem, critDevice, critNet). Calls receive every register except CS:IP and SS:SP — hence no reading of the user stack inside $OPEN or $ALLOC.

COMMAND

Découverte Discovery On range le manteau avant d’entrer Coats off before going in

Avant tout travail, DOS empile ES DS BP DI SI DX CX BX AX, note SS:SP de l’appelant, passe sur sa pile, et incrémente InDos. Tant que ce drapeau n’est pas zéro, un TSR sait qu’il ne doit pas rappeler DOS n’importe comment.

Before any work, DOS pushes ES DS BP DI SI DX CX BX AX, notes the caller’s SS:SP, switches to its stack, and increments InDos. While that flag is non-zero, a TSR knows it must not call DOS casually.

Intermédiaire Intermediate InDos · PDB_User_stack · Nsp/Nss

PDB_User_stack reçoit SS:SP pour qu’un EXEC puisse restaurer le père. Nsp / Nss offrent un niveau de réentrance pour qu’un INT 24 puisse rappeler DOS. Commentaire M043 : on les initialise même si InDos est déjà 1 — CROSSTALK 3.7 en dépend.

PDB_User_stack gets SS:SP so EXEC can restore the parent. Nsp / Nss give one level of re-entrancy so an INT 24 can call DOS again. Comment M043: they are initialised even if InDos is already 1 — CROSSTALK 3.7 depends on it.

Trois piles Three stacks

Découverte Discovery On ne range pas les assiettes avec les outils Plates and tools do not share a drawer

DOS a trois tiroirs de pile. Un appel clavier n’a pas le droit d’écraser ce qu’un appel disque est en train d’utiliser — surtout si une erreur disque (INT 24) rappelle DOS au milieu.

DOS has three stack drawers. A keyboard call must not overwrite what a disk call is using — especially if a disk error (INT 24) calls DOS again in the middle.

AuxStack IoStack DskStack

Intermédiaire Intermediate AH ≤ 12 vs le reste
  • AH = 0 (ABORT) → toujours DskStack (fermetures, INT 24 possible).
  • AH = 59h (GetExtendedError) → reste sur AuxStack : PRINT l’appelle depuis INT 24 / 28.
  • AH = 01–0Ch → IoStack, sauf si ErrorMode ≠ 0 (déjà dans un INT 24) : on reste sur Aux.
  • Tout le reste → DskStack, INT 28 interdit (IdleInt = 0), ressources serveur relâchées (INT 2Ah AH=82h).
  • AH = 0 (ABORT) → always DskStack (closes, possible INT 24).
  • AH = 59h (GetExtendedError) → stays on AuxStack: PRINT calls it from INT 24 / 28.
  • AH = 01–0Ch → IoStack, unless ErrorMode ≠ 0 (already in INT 24): stay on Aux.
  • Everything else → DskStack, INT 28 off (IdleInt = 0), server resources released (INT 2Ah AH=82h).

DISPATCH

Découverte Discovery AH n’est qu’un index AH is only an index

La table dans mstable.asm est une rangée de pointeurs : case 3Dh = $OPEN, case 48h = $ALLOC. Rien de magique. Les cases vides pointent sur NO_OP. Certaines sont marquées CAVEAT PROGRAMMER — officiellement non documentées ($SLEAZEFUNC, get DPB, set PDB…).

The table in mstable.asm is a row of pointers: slot 3Dh = $OPEN, slot 48h = $ALLOC. Nothing magic. Empty slots point at NO_OP. Some are marked CAVEAT PROGRAMMER — officially undocumented ($SLEAZEFUNC, get DPB, set PDB…).

Chemins courts et CALL 5 Fast paths and CALL 5

Découverte Discovery Parfois on n’entre même pas dans le hall Sometimes you never even enter the lobby

Get/Set PSP (50h, 51h, 62h), le piégeage Ctrl-C (33h) et un drapeau imprimante (64h) s’exécutent sur la pile du programme, interruptions coupées, sans toucher à InDos. Un serveur réseau peut les appeler à n’importe quel moment.

Get/Set PSP (50h, 51h, 62h), Ctrl-C trapping (33h) and a printer flag (64h) run on the program’s own stack, interrupts off, without touching InDos. A network server can call them at any moment.

Intermédiaire Intermediate PSP:0005

CP/M appelait le BDOS par un CALL 5. DOS met encore un far call à PSP:0005 (PDB_CPM_Call). Call_Entry réordonne la pile pour ressembler à un INT 21h, copie CL dans AH, et refuse tout numéro > MaxCall — seulement le vieux sous-ensemble.

CP/M called the BDOS with CALL 5. DOS still plants a far call at PSP:0005 (PDB_CPM_Call). Call_Entry reorders the stack to look like INT 21h, copies CL into AH, and rejects any number > MaxCall — the old subset only.

LeaveDos

Découverte Discovery Rendre les manteaux, IRET Coats back on, IRET

La routine revient dans LeaveDos : InDos--, restauration de SS:SP utilisateur, registres, IRET. CF dans les flags sauvés dit au programme si AX est une erreur.

The routine returns into LeaveDos: InDos--, restore the user SS:SP, registers, IRET. CF in the saved flags tells the program whether AX is an error.

Intermédiaire Intermediate A20OFF_COUNT

Si le compteur A20 n’est pas zéro, DOS éteint la ligne A20 avant l’IRET (M068) : certaines applis protégée-copie testent le wrap-around 8086 (FFFF:0010 → 0000:0000). Un EXEC vient de poser le bit EXECA20OFF ; le $DEALLOC qui suit (libération du chargeur) arme le compteur. Le dispatcher le consomme ici, pas dans ALLOC.

If the A20 counter is not zero, DOS turns the A20 line off before the IRET (M068): some copy-protected apps test the 8086 wrap-around (FFFF:0010 → 0000:0000). An EXEC has just set EXECA20OFF; the following $DEALLOC (loader teardown) arms the counter. The dispatcher consumes it here, not in ALLOC.

Technique Technical and DOS_FLAG, NOT EXECA20OFF

Juste après le CALL de la fonction, le bit EXEC est effacé — sauf si l’appel était AX=4B05h (ExecReady), qui revient par LeaveDos sans passer là. Le commentaire : ne rien ajouter entre le CALL et LeaveDos si ça doit s’exécuter aussi pour 4B05h.

Right after the function CALL, the EXEC bit is cleared — unless the call was AX=4B05h (ExecReady), which returns through LeaveDos without passing here. The comment: do not add anything between the CALL and LeaveDos if it must also run for 4B05h.
