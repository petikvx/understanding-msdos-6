SETVER

Un vieux programme affiche « Incorrect DOS version » et refuse de partir. Il a été écrit pour le 3.30 ou le 4.00 ; sous le 6.00 il s’arrête tout seul. SETVER ne le corrige pas : il lui ment le numéro de version.

An old program prints “Incorrect DOS version” and will not start. It was written for 3.30 or 4.00; under 6.00 it bails out. SETVER does not fix it: it lies about the version number.

SETVER FOO.EXE 3.30

DécouverteDiscovery SETVER FOO.EXE 3.30

Au lancement, beaucoup d’EXE demandent à DOS : « tu es quelle version ? » Si la réponse n’est pas celle qu’ils attendent, ils s’arrêtent — même s’ils tourneraient très bien.

SETVER FOO.EXE 3.30 ajoute FOO à une liste. Au prochain lancement de FOO seulement, DOS répond « 3.30 ». Les autres voient toujours 6.00. SETVER sans argument affiche la liste ; SETVER FOO.EXE /D retire l’entrée.

At startup many EXEs ask DOS: “which version are you?” If the answer is not the one they expect, they stop — even if they would run fine.

SETVER FOO.EXE 3.30 adds FOO to a list. On the next launch of FOO only, DOS answers “3.30”. Everyone else still sees 6.00. Bare SETVER lists the table; SETVER FOO.EXE /D removes the entry.

IntermédiaireIntermediate Scan_Special_Entries · M050

La recherche dans la table est insensible à la casse (M050). M060 : la table a quitté le noyau pour un device driver qui pose son adresse dans UU_IFS_DOS_CALL. A007 / A008 : entrées spéciales IBMCACHE et MS Windows.

The table search is case-insensitive (M050). M060: the table left the kernel for a device driver that plants its address in UU_IFS_DOS_CALL. A007 / A008: special IBMCACHE and MS Windows entries.

TechniqueTechnical Fake_Count

Fake_Count = 0FFh : reset à la version courante (code commenté Reset_Version). M006 : l’ancienne API « fake version call » n’est plus supportée (août 1990) — trop de gens s’en servaient n’importe comment.

Fake_Count = 0FFh: reset to the current version (commented Reset_Version). M006: the old “fake version call” API is no longer supported (August 1990) — too many people used it carelessly.

Où le mensonge est dit

DécouverteDiscovery AH=30h · AH=33h sous-fonctions

Cette question, c’est l’appel DOS n° 30h. DOS répond d’habitude 6.00. Si le programme est sur la liste SETVER, la réponse devient le numéro inventé — pour lui seulement. DIR et MEM voient toujours la vérité.

That question is DOS call 30h. DOS usually answers 6.00. If the program is on the SETVER list, the answer becomes the made-up number — for it only. DIR and MEM still see the truth.

IntermédiaireIntermediate RESTRICTED_BUILD

Variante de build : une liste blanche de programmes autorisés à s’exécuter (restrict.inc, 20-Jul-1992 bens) — disque « service » OEM. Autre forme de mensonge : tout le reste reçoit access denied.

Build variant: a whitelist of programs allowed to run (restrict.inc, 20-Jul-1992 bens) — OEM “service” disk. Another kind of lie: everyone else gets access denied.

TechniqueTechnical setver.c · device.asm

L’utilitaire est en C (setver.c, parse.c) plus un mini-driver (device.asm) que CONFIG.SYS charge pour que la table survive en mémoire.

DEVICE=SETVER.EXE

DécouverteDiscovery Un .EXE qui est aussi un pilote An .EXE that is also a driver

La liste doit être en mémoire avant que FOO.EXE parte. D’où, dans CONFIG.SYS :

DEVICE=C:\DOS\SETVER.EXE

Le même fichier sert deux fois : au boot, c’est un petit pilote qui tient la table en RAM ; à l’invite, SETVER FOO.EXE 3.30 réécrit la table dans SETVER.EXE sur le disque. Au reboot suivant, le pilote recharge ce qui a été gravé.

The list must be in memory before FOO.EXE starts. Hence, in CONFIG.SYS:

DEVICE=C:\DOS\SETVER.EXE

The same file does two jobs: at boot it is a tiny driver that holds the table in RAM; at the prompt, SETVER FOO.EXE 3.30 rewrites the table inside SETVER.EXE on disk. On the next reboot the driver reloads what was written.

IntermédiaireIntermediate table dans le binaire

Les paires nom/version sont stockées dans SETVER.EXE. Chaque ajout réécrit le fichier. D’où les sauvegardes avant d’y toucher, et les messages « version table is full ».

Name/version pairs are stored inside SETVER.EXE. Each add rewrites the file. Hence backups before touching it, and “version table is full”.

TechniqueTechnical dos.asm

Le lien EXEC : après TransPath / $OPEN, le nom canonique est comparé à la table avant de construire le PSP. Le mensonge est donc prêt quand le fils fera son premier AH=30h.
