cmd/mem/mem.c · membase.c

MEM.COM

La vue utilisateur de la page Mémoire. MEM marche la chaîne d’arènes, lit arena_name, interroge HIMEM et EMM386, et imprime ce que le simulateur First/Best/Last dessine à la main.

The user view of the Memory page. MEM walks the arena chain, reads arena_name, asks HIMEM and EMM386, and prints what the First/Best/Last simulator draws by hand.

Marcher les 4Dh / 5Ah

DécouverteDiscovery MEM

Sans switch : totaux conventionnel / supérieur / étendu. Les noms (MSDOS, COMMAND, HIMEM…) viennent des 8 caractères de l’en-tête d’arène, pas d’une magie.

No switch: conventional / upper / extended totals. The names (MSDOS, COMMAND, HIMEM…) come from the 8-character arena header, not from magic.

IntermédiaireIntermediate membase.c

Parcourt depuis arena_head (INT 21h AH=52h $GET_IN_VARS — CAVEAT PROGRAMMER). Owner 0 = free, owner 8 souvent DOS, sinon segment de PSP.

Walks from arena_head (INT 21h AH=52h $GET_IN_VARS — CAVEAT PROGRAMMER). Owner 0 = free, owner 8 often DOS, otherwise a PSP segment.

TechniqueTechnical chkvdisk.asm

VDISK (vieux RAM disk) plante un header en extended memory. MEM le détecte pour ne pas compter deux fois. Même souci que HIMEM / 16 Mo EISA.

/CLASSIFY /DEBUG /FREE /MODULE

DécouverteDiscovery /C

/C : par module (ce que chaque programme occupe). /D : tout, y compris les drivers. /F : trous. /M nom : un seul module. C’est le commentaire en tête de mem.c.

/C: per module (what each program occupies). /D: everything, drivers included. /F: holes. /M name: one module. That is the comment at the top of mem.c.

IntermédiaireIntermediate memex.c

Regroupe les blocs du même owner (un programme peut avoir plusieurs arènes : env + code + overlays). Affiche aussi les UMB si LINKSTATE.

Groups blocks with the same owner (a program may have several arenas: env + code + overlays). Also shows UMBs if LINKSTATE.

TechniqueTechnical memctrlc.c

Ctrl-C pendant un long /DEBUG : handler C maison. MEM est l’un des rares utilitaires noyau écrits en C (comme FDISK, SETVER).

Interroger HIMEM et EMM386

DécouverteDiscovery xms.asm · emm386.asm

Les totaux « Extended » / « Expanded » ne viennent pas des arènes : INT 2Fh XMS et INT 67h EMS. Sans les drivers, ces lignes sont à zéro ou absentes.

The “Extended” / “Expanded” totals are not from arenas: INT 2Fh XMS and INT 67h EMS. Without the drivers those lines are zero or missing.

IntermédiaireIntermediate HMA

MEM indique si DOS est en HMA (DOS=HIGH). Ça se voit aussi : le premier bloc conventionnel est plus petit.

MEM says whether DOS is in the HMA (DOS=HIGH). You can see it too: the first conventional block is smaller.

TechniqueTechnical wintest.asm

Détection Windows : les chiffres changent dans une boîte DOS. MEM doit mentir un peu, ou du moins ne pas paniquer.
