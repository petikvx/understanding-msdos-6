45/runtime · 45/beef/cw

BQB50 · COW

Sous l’interpréteur : une bibliothèque de ~148 .asm (PRINT, SCREEN, PLAY, fichiers) et le toolkit fenêtres COW, partagé avec DOSSHELL. Sans ça, QBasic n’a ni graphismes ni menus.

Under the interpreter: a library of ~148 .asm files (PRINT, SCREEN, PLAY, files) and the COW window toolkit, shared with DOSSHELL. Without them QBasic has neither graphics nor menus.

La lib déjà construite

DécouverteDiscovery 45/qb5/qbas/bqb50.lib

Une copie pré-linkée est dans l’arbre. Pour la reconstruire : \45\RUNTIME\QBASIC, TL=\45\TL\BIN, NMAKE. Fuite mémoire de NMAKE : relancer, il reprend.

A pre-linked copy sits in the tree. To rebuild: \45\RUNTIME\QBASIC, TL=\45\TL\BIN, NMAKE. NMAKE memory leak: restart, it continues.

IntermédiaireIntermediate b$ préfixe

Les symboles runtime s’appellent b$… (BASIC). L’interpréteur les appelle depuis extort.asm (« exit to runtime »). Math copro : switch EM_MATH dans version.h.

Runtime symbols are named b$… (BASIC). The interpreter calls them from extort.asm (“exit to runtime”). Coprocessor math: EM_MATH switch in version.h.

TechniqueTechnical crt + herc

runtime/crt/ : helpers C. runtime/herc/ : Hercules. cmd/qbasic/msherc.com est le stub livré pour les cartes Herc.

148 fichiers .asm

DécouverteDiscovery ce que fait PRINT

Chaque mot-clé « visible » a un module : I/O fichiers, graphismes, chaînes, erreurs. L’interpréteur ne redessine pas un cercle : il appelle le runtime.

Each “visible” keyword has a module: file I/O, graphics, strings, errors. The interpreter does not redraw a circle: it calls the runtime.

IntermédiaireIntermediate messages

45/qbusa/strings/qbasmsgs.txt (et qbfrn, qbger…) : « QBasic cannot continue », « Undefined function ». Localiser = retokeniser, pas recompiler tout l’interpréteur.

45/qbusa/strings/qbasmsgs.txt (and qbfrn, qbger…): “QBasic cannot continue”, “Undefined function”. Localizing = retokenizing, not recompiling the whole interpreter.

TechniqueTechnical 45/runtime/rt/

Ouvre l’arbre dans l’explorateur. Les noms sont souvent obscurs (b$…) ; les commentaires d’en-tête restent ceux de QB 4.x (© 1986).

Le même COW que DOSSHELL

DécouverteDiscovery 45/beef/cw

Character-Oriented Windows : fenêtres texte, menus, souris. DOSSHELL et QBasic ne réinventent pas une UI. D’où le même « look » gris/bleu.

Character-Oriented Windows: text windows, menus, mouse. DOSSHELL and QBasic do not reinvent a UI. Hence the same grey/blue look.

IntermédiaireIntermediate kernel + user

cw/kernel/ : mémoire, souris, INT 24. cw/user/ : boutons, listes, menus. Doc dans 45/doc/cowapi.doc.

cw/kernel/: memory, mouse, INT 24. cw/user/: buttons, lists, menus. Docs in 45/doc/cowapi.doc.

TechniqueTechnical Tandy

cowtandy.lib : variante clavier/vidéo Tandy 1000. buildlqb.bat construit la lib « little QB ».
