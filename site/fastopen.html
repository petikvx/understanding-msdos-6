cmd/fastopen/ · fastopen.txt (J.K.)

FASTOPEN

Un cache de chemins, pas de secteurs. Les bases DOS rouvrent le même fichier cent fois ; chaque OPEN redescend la FAT et le répertoire. FASTOPEN retient « ce nom = ce premier cluster / cette entrée » en RAM.

A cache of paths, not sectors. DOS databases reopen the same file a hundred times; each OPEN walks FAT and directory again. FASTOPEN remembers “this name = this first cluster / this entry” in RAM.

FASTOPEN C:=50

DécouverteDiscovery Une petite base par lecteur A small database per drive

Le doc de conception : « conceptually FASTOPEN itself is a database maintained by DOS ». On indique le lecteur et combien d’entrées. TSR installable par l’utilisateur.

The design doc: “conceptually FASTOPEN itself is a database maintained by DOS”. You name the drive and how many entries. User-installable TSR.

IntermédiaireIntermediate fastopen.inc

Le noyau a des crochets fastopen.inc / fastxxxx.inc (déjà inclus dans open.asm). Sans le TSR, les hooks sont no-op.

The kernel has hooks in fastopen.inc / fastxxxx.inc (already included from open.asm). Without the TSR, the hooks are no-ops.

TechniqueTechnical fastp.asm · fastsm.asm

Lookup / store / invalidate. Un RENAME ou DELETE doit casser l’entrée — sinon on ouvre un fantôme. Même problème que le cache de dpb_free_cnt.

Où ça se branche

DécouverteDiscovery GETPATH

Avant de relire tout le répertoire, DOS demande à FASTOPEN : « tu as déjà C:\DB\CLIENT.DAT ? » Oui → DIR_FIRST et secteur d’entrée tout de suite, puis la SFT se remplit comme d’habitude.

Before rereading the whole directory, DOS asks FASTOPEN: “do you already have C:\DB\CLIENT.DAT?” Yes → DIR_FIRST and entry sector at once, then the SFT fills as usual.

IntermédiaireIntermediate pas un cache de données

Les octets du fichier passent encore par SMARTDRV / BUFFERS. FASTOPEN n’évite que la recherche du nom. Complémentaire, pas concurrent.

The file’s bytes still go through SMARTDRV / BUFFERS. FASTOPEN only skips looking up the name. Complementary, not competing.

TechniqueTechnical A005 lost clusters

close.asm mentionne PTM 3718 : clusters perdus avec FASTOPEN installé. Invalider trop tard / trop tôt casse ALLOCATE. Les caches s’empilent, les bugs aussi.

Ce qu’il ne faut pas en attendre

DécouverteDiscovery Inutile sur un fichier ouvert une fois Useless for a file opened once

COMPILE.EXE lu une fois : zéro gain. Un .DBF rouvert à chaque requête : visible. Occupé de la RAM conventionnelle ou UMB.

COMPILE.EXE read once: zero gain. A .DBF reopened on every query: visible. It occupies conventional RAM or a UMB.

IntermédiaireIntermediate réseau

Sur un lecteur redir, le serveur est la source de vérité. FASTOPEN est local. D’où les mises en garde des manuels sur les lecteurs réseau.

On a redirected drive the server is the source of truth. FASTOPEN is local. Hence the manuals’ warnings about network drives.

TechniqueTechnical fastinit.asm

L’init réserve le tableau et accroche le multiplex. Même patron que SHARE : le noyau appelle, le TSR répond, sinon no-op.
