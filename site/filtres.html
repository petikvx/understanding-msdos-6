Filtres et comparateurs Filters and comparators

Les pipes de COMMAND sont des fichiers temporaires. Ces cinq externes sont ce qu’on branche aux deux bouts : paginer, chercher, trier, différencier. SORT tient dans 64 Ko. FC a un commentaire « The algorithm that immediately follows does not work ».

COMMAND’s pipes are temporary files. These five externals are what you plug at both ends: page, search, sort, diff. SORT fits in 64 KB. FC has a comment: “The algorithm that immediately follows does not work”.

MORE — une page, une touche

DécouverteDiscovery DIR | MORE

Lit stdin jusqu’à remplir l’écran, écrit -- More --, attend une touche. Le nombre de lignes vient de la zone BIOS (CRT_Rows à 40:84h), pas d’une constante 25 — sauf Japon, figé à 24×80.

Reads stdin until the screen is full, writes -- More --, waits for a key. Line count comes from the BIOS area (CRT_Rows at 40:84h), not a hard 25 — except Japan, frozen at 24×80.

IntermédiaireIntermediate AN003 CR-LF

PTM 3860 (Bill L, 17-Sep-87) : ajouter CR-LF pour rester compatible DOS 3.3. HELP reprend le même code de hauteur d’écran (« Code taken from MORE.COM » dans helper.asm).

PTM 3860 (Bill L, 17-Sep-87): add CR-LF to stay DOS 3.3 compatible. HELP reuses the same screen-height code (“Code taken from MORE.COM” in helper.asm).

FIND « chaîne »

DécouverteDiscovery /V /C /N /I

Une seule chaîne, entre guillemets doubles (deux "" pour en embarquer un). Sans fichier : stdin. Errorlevel 0 = des matchs, 1 = aucun, 2 = erreur — le IF ERRORLEVEL des .BAT s’en sert.

One string only, in double quotes (two "" to embed one). No file: stdin. Errorlevel 0 = some matches, 1 = none, 2 = error — BAT IF ERRORLEVEL uses it.

IntermédiaireIntermediate M.A.U. 1982

Né FIND chez IBM après s’être appelé autrement. V1.1 23-Aug-82. Les lignes plus longues que le buffer « will bomb the program ». /I (ignore casse) est plus tardif ; HELP réutilise sa table de majuscules DOS.

Born FIND at IBM after another name. V1.1 23-Aug-82. Lines longer than the buffer “will bomb the program”. /I (ignore case) came later; HELP reuses its DOS uppercase table.

TechniqueTechnical find.asm

Scan octet à octet, pas d’automate. DBCS conscient dans les builds asiatiques. Un fichier à la fois, nom affiché avant les lignes.

SORT — 64 Ko et pas plus

DécouverteDiscovery /R · /+n

Lit stdin jusqu’à EOF, trie, écrit stdout. /R inverse. /+n commence à la colonne n. Au-delà de 64 Ko : « Insufficient memory to allocate SORT buffer ».

Reads stdin to EOF, sorts, writes stdout. /R reverses. /+n starts at column n. Beyond 64 KB: “Insufficient memory to allocate SORT buffer”.

IntermédiaireIntermediate Comment the Damn source

18-Mar-83, MZ (Mark Zbikowski) : « Fix CR-LF at end of buffer / Fix small file sorting / Comment the Damn source ». Le tri est une table de pointeurs sur les lignes dans un unique segment — d’où le plafond 64 Ko.

18-Mar-83, MZ (Mark Zbikowski): “Fix CR-LF at end of buffer / Fix small file sorting / Comment the Damn source”. The sort is a pointer table over lines in a single segment — hence the 64 KB ceiling.

TechniqueTechnical sort.asm

Comparaison via la table de collation NLS (DOS 3.30, RW/IBM) puis attributs étendus / code page en 4.0. DIR | SORT | MORE est donc trois processus, trois temporaires (page COMMAND).

FC et COMP

DécouverteDiscovery lignes contre octets

COMP : dix premières différences, jokers, options /d /a /l /n= /c. FC : soit octet à octet, soit « resync » de lignes (le diff des humains). DISKCOMP compare des pistes ; FC/COMP comparent des fichiers.

COMP: first ten differences, wildcards, /d /a /l /n= /c. FC: either byte-by-byte or line “resync” (the human diff). DISKCOMP compares tracks; FC/COMP compare files.

IntermédiaireIntermediate pas de hash

fc.c : « No hashing of lines needs to be done; hashing only speedily tells you when things are different, not the same. Most files … largely the same. Thus, hashing buys nothing. »

fc.c: “No hashing of lines needs to be done; hashing only speedily tells you when things are different, not the same. Most files … largely the same. Thus, hashing buys nothing.”

TechniqueTechnical KGS was here 
/* fc.c — The algorithm that immediately follows does not work.
   There is an error somewhere in the range of lines 11 on.
   An alternative explanation follows.                    KGS */

L’algo de resync (deux buffers, indices xc/yc/xp/yp, « sync range ») est laissé en commentaire mort, remplacé plus bas. COMP est du C plus simple : deux malloc, comparer, s’arrêter à 10.

The resync algo (two buffers, xc/yc/xp/yp, “sync range”) is left as a dead comment, replaced below. COMP is simpler C: two mallocs, compare, stop at 10.
