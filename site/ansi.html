dev/ansi/ansi.asm · « FANCY CONSOLE DRIVER »

ANSI.SYS

Le pilote qui rend CON intelligent : couleurs, curseur, PROMPT $e[1;33m. Sans lui, ECHO n’écrit que des glyphes. Avec lui, une séquence CSI devient un appel INT 10h.

The driver that makes CON clever: colours, cursor, PROMPT $e[1;33m. Without it, ECHO only writes glyphs. With it, a CSI sequence becomes an INT 10h call.

Séquences

DécouverteDiscovery ESC [ 2 J

Un programme écrit vers le handle 1. ANSI reconnaît ESC puis [, accumule les paramètres, et exécute : effacer, déplacer, changer d’attribut. CLS de COMMAND peut s’en passer ; beaucoup de prompts colorés, non.

A program writes to handle 1. ANSI recognises ESC then [, gathers parameters, and acts: clear, move, change attribute. COMMAND’s CLS can live without it; many coloured prompts cannot.

IntermédiaireIntermediate ansi.inc · ansivid.inc

Tables de modes vidéo (CGA…VGA). P4532 : neige sur CGA au scroll. P4533 : scroll cassé en modes Dh–13h. Bug#173 : on pouvait descendre d’une ligne sous le bas de l’écran ($e[25;3H $e[1B).

Video-mode tables (CGA…VGA). P4532: CGA snow on scroll. P4533: scroll broken in modes Dh–13h. Bug#173: you could go one line below the bottom ($e[25;3H $e[1B).

TechniqueTechnical ioctl.asm

ANSI a son propre IOCTL (page IOCTL) pour interroger / forcer le mode. C’est un device CON de plus dans la chaîne : programme → ANSI → CON BIOS.

Remplacer CON

DécouverteDiscovery DEVICE=ANSI.SYS

SYSINIT charge le driver en overlay. Il s’installe comme nouveau CON : les bits devid_device_con_in/out de la SFT pointent ici.

SYSINIT loads the driver as an overlay. It installs as the new CON: the SFT’s devid_device_con_in/out bits point here.

IntermédiaireIntermediate raw vs cooked

En cooked, ANSI voit chaque octet. En raw (IOCTL), les programmes plein écran by-passent souvent les séquences et parlent à INT 10h directement.

In cooked mode ANSI sees every byte. In raw (IOCTL), full-screen programs often skip sequences and talk to INT 10h themselves.

TechniqueTechnical parser.asm

Machine à états pour les paramètres séparés par ;. D375 : la séquence elle-même doit honorer /X (clavier étendu), pas seulement la ligne de commande.

/X /L /K

DécouverteDiscovery Trois interrupteurs de DOS 4 Three DOS 4 switches

/X : fonctions clavier étendues. /L : imposer le nombre de lignes. /K : désactiver le clavier étendu (D479).

/X: extended keyboard functions. /L: enforce line count. /K: disable the extended keyboard (D479).

IntermédiaireIntermediate Mod 25/30

GHG : le scroll « flashait » sur PS/2 modèle 25/30. P4766 : en mode 11h/12h, l’effacement laissait 5 lignes en bas.

GHG: scroll “flashed” on PS/2 model 25/30. P4766: in modes 11h/12h, erase left 5 lines at the bottom.

TechniqueTechnical ansiinit.asm

Init jette après DEVICE=. La table VIDEO_MODE_TABLE (P1767) doit être remplie avant le premier ESC — sinon le premier CLS est faux.
