cmd/doskey — 1989, multiplex 4800h

DOSKEY

TSR qui vole la lecture de ligne à COMMAND. Flèches, F7, macros ls=dir /w. L’historique est un anneau d’ASCIIZ avec un octet volontairement inutilisable pour distinguer vide et plein.

A TSR that steals line input from COMMAND. Arrows, F7, macros ls=dir /w. History is a ring of ASCIIZ strings with one deliberately unusable byte so empty and full can be told apart.

À la place de AH=0Ah

DécouverteDiscovery ↑ ↓ F7 F8 F9

COMMAND lit encore via INT 21h AH=0Ah (buffered input). DOSKEY s’installe dessus (et sur INT 2Fh). Les flèches déplacent buf_current dans l’anneau. F7 dump l’historique, F8 cherche un préfixe, F9 rappelle par numéro.

COMMAND still reads via INT 21h AH=0Ah (buffered input). DOSKEY hooks that (and INT 2Fh). Arrows move buf_current around the ring. F7 dumps history, F8 searches a prefix, F9 recalls by number.

IntermédiaireIntermediate /REINSTALL /BUFSIZE

Le transient (trans.asm) parse /REINSTALL, /BUFSIZE, /HISTORY (/H), /MACROS (/M), /INSERT, /OVERSTRIKE. Relancer DOSKEY sans /REINSTALL parle au résident déjà là via INT 2Fh AX=4800h.

The transient (trans.asm) parses /REINSTALL, /BUFSIZE, /HISTORY (/H), /MACROS (/M), /INSERT, /OVERSTRIKE. Relaunching DOSKEY without /REINSTALL talks to the existing resident via INT 2Fh AX=4800h.

TechniqueTechnical our_version = 0AA02h 
; gendef.inc
our_version  =  0aa02h
; "a return code of 4800h is the indication that nobody
;  hooked that interrupt" — donc le stamp ne doit PAS être 4800h.

; doskey.asm — install
hipper_install = 0
; si 1 : init_main puis rep movsb (buffers sur le code d'init) puis INT 27h

Le flag hipper_install est à 0 dans cette source : on saute à init_main sans recouvrir le transient. INT 27h (pas 21h/31h) pour rester TSR « à l’ancienne ». Données d’instance au-dessus de ORG 100h : template COMMAND, pointeurs de buffer, insert par défaut.

The hipper_install flag is 0 in this source: jump to init_main without overlaying the transient. INT 27h (not 21h/31h) to stay old-school TSR. Instance data above ORG 100h: COMMAND template, buffer pointers, default insert.

Macros

DécouverteDiscovery DOSKEY d=dir $*

macro_base / macro_last / macro_end : un second espace dans le même segment. $*, $1…$9, $T (enchaîner). Flag MAC_EXPAND dans le mot d’état de ligne : on réinjecte le texte expansé comme s’il avait été tapé.

macro_base / macro_last / macro_end: a second workspace in the same segment. $*, $1…$9, $T (chain). MAC_EXPAND flag in the line-state word: expanded text is reinjected as if typed.

IntermédiaireIntermediate template.asm

Les touches étendues (scan + 0) contre les ASCII. Espace à 7Fh : imprimables, sauf Ctrl-Backspace. DBCS / Corée : INT 16h et fonctions interim F0h/F1h — le même dossier a des ifdef KOREA.

Extended keys (scan + 0) versus ASCII. Space through 7Fh: printable, except Ctrl-Backspace. DBCS / Korea: INT 16h and interim F0h/F1h — the same folder has ifdef KOREA.

TechniqueTechnical Windows 386 instance

w386_instptr, w386_instseg1/2 : DOSKEY s’enregistre auprès du VxD pour que chaque VM Windows ait son propre historique. Sans ça, les flèches d’une fenêtre rejoueraient celles d’une autre.

L’octet interdit

DécouverteDiscovery vide ≠ plein

Un anneau où tête = queue peut vouloir dire vide ou plein. buffer.asm réserve un octet mort : « There will always be one unusable byte in the buffer. »

A ring where head = tail can mean empty or full. buffer.asm keeps one dead byte: “There will always be one unusable byte in the buffer.”

IntermédiaireIntermediate split configuration

Si buf_back < buf_front, l’historique est coupé en deux bouts physiques. get_buflen / nxtbuf_x / buffer_compare gèrent le wrap. Insertion : bits « était déjà split », « on a wrappé en écrivant ».

If buf_back < buf_front, history is split across two physical ends. get_buflen / nxtbuf_x / buffer_compare handle the wrap. Insertion tracks “was already split” and “we wrapped while writing”.
