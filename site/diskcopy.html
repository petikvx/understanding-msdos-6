cmd/diskcopy · cmd/diskcomp

DISKCOPY · DISKCOMP

Copie et comparaison piste à piste, pas fichier à fichier. La FAT n’est pas interprétée : boot, FAT, racine et données partent tels quels. « Copy another (Y/N)? » : une seule charge, plusieurs cibles.

Track-by-track copy and compare, not file-by-file. FAT is not interpreted: boot, FAT, root and data go as-is. “Copy another (Y/N)?”: one load, several targets.

Image exacte

DécouverteDiscovery DISKCOPY A: B:

XCOPY ne copie pas le boot ni les fichiers cachés système de la même façon. DISKCOPY clone le média. Un seul lecteur : swap source/cible, autant de passes que la RAM le permet.

XCOPY does not copy the boot or hidden system files the same way. DISKCOPY clones the media. One drive: swap source/target, as many passes as RAM allows.

IntermédiaireIntermediate INT 13 · BPB

Lit le BPB source pour connaître pistes/têtes. IOCTL generic (page MODE/IOCTL) peut formater la cible au même géométrie. SUBST/JOIN sont refusés.

Reads the source BPB for tracks/heads. Generic IOCTL (MODE/IOCTL page) can format the target to the same geometry. SUBST/JOIN are refused.

TechniqueTechnical ORG 100h · BEGIN

diskcopy.asm : spec « Diskette to diskette complete copy ». Pas de disque dur — CHS floppy only. Les buffers occupent la TPA (comme COMMAND le calcule dans BYTCNT).

DISKCOMP

DécouverteDiscovery Même chemin, compare Same path, compare

Code frère (dcomp*.asm). Signale la première piste différente. Utile après DISKCOPY pour les médias douteux.

Sibling code (dcomp*.asm). Reports the first differing track. Useful after DISKCOPY on doubtful media.

IntermédiaireIntermediate FC vs DISKCOMP

FC compare des fichiers. DISKCOMP compare des secteurs y compris les non alloués. Un cluster libre différent → DISKCOMP râle, FC non.

FC compares files. DISKCOMP compares sectors including unallocated ones. A different free cluster → DISKCOMP complains, FC does not.

TechniqueTechnical même parseur

Les deux partagent le style IBM spec header et un parseur de lecteurs. Historique : utilitaires SAL (System Adaptation Layer) IBM.

Formater si besoin

DécouverteDiscovery /V

Cible vierge : DISKCOPY appelle le formatage (même INT 13 que FORMAT) puis copie. Verify optionnel.

Blank target: DISKCOPY calls format (same INT 13 as FORMAT) then copies. Optional verify.

IntermédiaireIntermediate 1.44 vs 720

Géométries incompatibles → erreur. On ne « gonfle » pas une 720 Ko en 1.44 par DISKCOPY.

Mismatched geometries → error. You do not “inflate” a 720 KB disk to 1.44 with DISKCOPY.

TechniqueTechnical copyinit.asm

Init détermine les BDS des deux lecteurs via IO.SYS. Media check entre chaque swap.
