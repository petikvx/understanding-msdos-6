/EDCOM · /QHELP — le même QBASIC.EXE

EDIT · HELP

Deux minuscules .COM qui relancent QBasic avec un switch. EDIT est l’éditeur (sans RUN). HELP (celui de DOS, help.hlp) est un lecteur d’aide — distinct de cmd/help/HELP.EXE qui spawn /?.

Two tiny .COM files that relaunch QBasic with a switch. EDIT is the editor (no RUN). HELP (the DOS one, help.hlp) is a help viewer — distinct from cmd/help/HELP.EXE which spawns /?.

EDIT AUTOEXEC.BAT

DécouverteDiscovery après EDLIN

Écran plein, menus, souris. C’est QBasic sans l’invite OK : le switch /EDCOM cache l’interpréteur. EDLIN reste dans cmd/edlin/ pour les machines trop petites.

Full screen, menus, mouse. It is QBasic without the OK prompt: the /EDCOM switch hides the interpreter. EDLIN stays in cmd/edlin/ for machines that are too small.

The editor itself: 45/qb5/ir/qedit.asm + 45/qb5/uq/ (files, search, windows). Saved colors (warning in defcolor.c).

QHelp n’est pas HELP.EXE

DécouverteDiscovery deux HELP

HELP DIR peut lancer soit le petit cmd/help (liste + /?), soit ce viewer plein écran selon ce qui est dans le PATH. Le viewer lit HELP.HLP (commandes DOS) via le moteur d’aide QBasic (hengine.asm).

HELP DIR may run either the small cmd/help (list + /?) or this full-screen viewer, depending on PATH. The viewer reads HELP.HLP (DOS commands) through the QBasic help engine (hengine.asm).

IntermédiaireIntermediate CMD_SW_QHELP

Le bit CMD_SW_QHELP change les messages de statut et les boutons. Topic limité à 40 caractères (cbmaxTOPIC, rustine QH1). Version viewer 0460h dans uifileio.asm.

The CMD_SW_QHELP bit changes status messages and buttons. Topic capped at 40 characters (cbmaxTOPIC, QH1 patch). Viewer version 0460h in uifileio.asm.
