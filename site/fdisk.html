FDISK

Avant FAT, avant FORMAT : quatre cases dans le secteur 0 du disque dur, chacune un type, un début, une taille, un bit « active ». C’est le plan que le BIOS et le boot lisent pour savoir quelle partition amorcer.

Before FAT, before FORMAT: four slots in hard-disk sector 0, each a type, a start, a size, an “active” bit. That is the map the BIOS and the boot read to know which partition to start.

Quatre entrées

DécouverteDiscovery Un disque, plusieurs lettres One disk, several letters

C: est souvent la partition primaire active. D: une logique dans une partition étendue. FDISK ne formate pas : il écrit la table, puis il faut FORMAT chaque volume. Une seule entrée active à la fois — c’est elle que le MBR lance.

C: is often the active primary partition. D: a logical volume inside an extended partition. FDISK does not format: it writes the table, then each volume needs FORMAT. Only one entry is active — that is the one the MBR starts.

IntermédiaireIntermediate find_free_partition

partinfo.c parcourt les 4 slots. Vide = sys_id nul. find_active_partition cherche le bit actif. int13.c parle au BIOS pour lire/écrire le MBR. fdboot.asm / bootrec.asm le code d’amorçage du MBR lui-même.

partinfo.c walks the 4 slots. Empty = null sys_id. find_active_partition looks for the active bit. int13.c talks to the BIOS to read/write the MBR. fdboot.asm / bootrec.asm is the MBR boot code itself.

TechniqueTechnical C14 non-DOS

Mars 1990 (EGH C14) : on peut enfin effacer une partition qui n’est pas DOS. find_non_dos_partition = sys_id ni nul, ni DOS12/16/NEW, ni EXTENDED. C15 : reconnaître d’autres types.

March 1990 (EGH C14): we can finally delete a non-DOS partition. find_non_dos_partition = sys_id neither null, nor DOS12/16/NEW, nor EXTENDED. C15: recognise more types.

Le programme d’installation commente : DOS12==1, DOS16==4, DOSNEW==6 « huge partition > 32 meg ». FORMAT écrit alors BPB_BIGTOTALSECTORS. Pas de type FAT32 : trop tôt.

Setup comments: DOS12==1, DOS16==4, DOSNEW==6 “huge partition > 32 meg”. FORMAT then writes BPB_BIGTOTALSECTORS. No FAT32 type: too early.

Partition étendue Extended partition

DécouverteDiscovery Plus que quatre volumes More than four volumes

Quatre primaires, c’est peu. Une entrée de type 05 contient une chaîne de volumes logiques, chacun avec un mini-MBR. FDISK affiche D:, E:, …

Four primaries is few. A type-05 entry holds a chain of logical volumes, each with a mini-MBR. FDISK shows D:, E:, …

find_free_ext / comments: up to 23 extended entries. Only DOS12/16/NEW are usable DOS volumes in that chain.

TechniqueTechnical reboot.asm

Après un changement de table, FDISK propose souvent un reboot : le BIOS et IO.SYS ont déjà lu l’ancien MBR. reboot.asm s’en charge. Les menus sont en C (c_menus.c, mainmenu.c) — rare îlot C dans un océan d’assembleur.

After a table change, FDISK often offers a reboot: the BIOS and IO.SYS already read the old MBR. reboot.asm handles that. Menus are in C (c_menus.c, mainmenu.c) — a rare C island in a sea of assembly.
