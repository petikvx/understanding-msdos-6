SHARE

DOS seul ne sait pas que deux programmes tiennent le même fichier. SHARE s’installe et remplit la table JShare : fusionner les SFT, refuser un second open, poser des verrous d’octets. Sans lui, les modes SHARING_* de OPEN sont des vœux.

DOS alone does not know two programs hold the same file. SHARE installs and fills the JShare table: collapse SFTs, refuse a second open, set byte locks. Without it, the SHARING_* modes on OPEN are wishes.

Une table de far calls

DécouverteDiscovery Le noyau appelle dans le vide… sauf si SHARE est là The kernel calls into the void… unless SHARE is there

Les stubs de dos/share.asm / lock.asm rendent « pas d’erreur » tant que SHARE n’est pas chargé. Une fois lancé, il patch JShare. $Open appelle JShare + 12*4 (ShCol) pour collapser deux SFT identiques.

Stubs in dos/share.asm / lock.asm return “no error” until SHARE is loaded. Once running, it patches JShare. $Open calls JShare + 12*4 (ShCol) to collapse two identical SFTs.

IntermédiaireIntermediate gshare.asm · M003

Bug #2425 : ne pas chaîner une SFT à elle-même. sf_UID / sf_PID / sf_MFT identifient le fichier ouvert. M001 retire le switch /NC (« skip_check »).

Bug #2425: do not chain an SFT to itself. sf_UID / sf_PID / sf_MFT identify the open file. M001 removes the /NC switch (“skip_check”).

TechniqueTechnical Installed = True

Le noyau se compile avec Installed = True : les appels passent par INT 2Fh multiplex plutôt que d’être liés en dur. SHARE.EXE est un TSR comme un autre.

Compatibility vs deny-*

DécouverteDiscovery Le mode 70h des FCB réseau Network FCB mode 70h

Compatibility (DOS 2) : « je suis tout seul ». Deny-write : les autres peuvent lire. SHARING_NET_FCB (70h) : cas spécial déjà vu à la fermeture du JFN.

Compatibility (DOS 2): “I am alone”. Deny-write: others may read. SHARING_NET_FCB (70h): special case already seen when freeing the JFN.

IntermédiaireIntermediate sharing_violation

DOS_Open / SHARE_ERROR : en compatibility, INT 24 ; sinon erreur 32. Un second WRITER sur un deny-write échoue ici, pas dans FAT.

DOS_Open / SHARE_ERROR: in compatibility, INT 24; otherwise error 32. A second WRITER on deny-write fails here, not in FAT.

TechniqueTechnical sf_chain

Les SFT du même fichier sont liées par sf_chain. C’est cette liste que ShCol parcourt au lieu d’en allouer une nouvelle.

Verrous

DécouverteDiscovery AH=5Ch

Même fichier ouvert deux fois : on peut verrouiller une plage d’octets. Sans SHARE, $LockOper est un stub. Windows et les bases DOS s’en servent.

Same file opened twice: you can lock a byte range. Without SHARE, $LockOper is a stub. Windows and DOS databases use it.

DOS_LOCK / Lock_Check / Lock_Violation. dispatch.txt files them under “STUB MODULES”. Error 33 = lock violation.
