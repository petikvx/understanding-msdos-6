MS-DOS 6 · cmd/command/

COMMAND.COM

C’est lui qui tape le nom que $EXEC charge. Deux corps dans un fichier : un résident minuscule qui survit à FOO.COM, un transient en haut de la RAM qu’on peut écraser — et recharger grâce à un checksum. Les « pipes » ne sont pas des tuyaux : ce sont deux fichiers temporaires.

This is what types the name $EXEC loads. Two bodies in one file: a tiny resident that survives FOO.COM, a transient at the top of RAM that may be overwritten — and reloaded via a checksum. “Pipes” are not pipes: they are two temporary files.

    Trois morceaux dans un .COM Three pieces in one .COM

    Découverte Discovery Ce qui reste, ce qu’on jette, ce qu’on relit What stays, what is thrown, what is reread

    L’en-tête de command1.asm le dit : trois parts. Le résident gère Ctrl-C, l’erreur disque, et INT 2Eh (« exécute cette ligne »). L’init s’efface après le premier démarrage. Le transient contient DIR, COPY, le prompt — tout ce qui est gros. Un programme gourmand l’écrase ; au retour, un checksum décide s’il faut le relire depuis le disque (COMSPEC).

    The header of command1.asm says it: three parts. The resident handles Ctrl-C, disk errors, and INT 2Eh (“run this line”). Init is discarded after first boot. The transient holds DIR, COPY, the prompt — everything large. A hungry program overwrites it; on return a checksum decides whether to reread it from disk (COMSPEC).

    Intermédiaire Intermediate RESGROUP · TRANGROUP · TPA

    comseg.asm : DATARES + CODERES (+ INIT, TAIL) forment le résident. TRANCODE + TRANDATA + TRANSPACE + TRANTAIL forment le transient, chargé en haut de la mémoire. Entre les deux : la TPA (Transient Program Area) — c’est là que $EXEC pose FOO.COM.

    readme.txt : TRANDATA a des valeurs initiales et entre dans le checksum. TRANSPACE est modifié à chaque cycle et exclu — on le traite comme non initialisé à chaque commande.

    comseg.asm: DATARES + CODERES (+ INIT, TAIL) are the resident. TRANCODE + TRANDATA + TRANSPACE + TRANTAIL are the transient, loaded at the top of memory. Between them: the TPA (Transient Program Area) — that is where $EXEC plants FOO.COM.

    readme.txt: TRANDATA has initial values and is in the checksum. TRANSPACE is changed every cycle and is excluded — treat it as uninitialized for every command.

    Technique Technical ChkSum · LoadCom

    cmd/command/command2.asm

    mov  ds, TrnSeg
mov  si, 100h
mov  cx, TranDataEnd - 100h
shr  cx, 1
lodsw / add dx, ax / adc dx, 0

    Somme 16 bits avec retenue, depuis l’équivalent du PSP:100h jusqu’à la fin de TRANDATA. TRANSPACE n’y est pas.

    16-bit sum with carry, from the PSP:100h equivalent to the end of TRANDATA. TRANSPACE is not included.

    call ChkSum
; si DX ≠ Sum sauvé → LoadCom
; rouvre COMSPEC, relit le transient

    Un programme qui n’a pas tout pris évite le reload — le commentaire d’en-tête le revendique. Novell RPL (M038) casse ce schéma en rendant de la RAM trop tôt.

    A program that did not take everything skips the reload — the header comment boasts about that. Novell RPL (M038) breaks the scheme by giving RAM back too early.

    La boucle de commande The command loop

    Découverte Discovery Pas toujours un prompt Not always a prompt

    On croit que COMMAND attend une ligne. En réalité il interroge d’abord : est-on au milieu d’un pipe ? d’un FOR ? d’un .BAT ? Seulement sinon, et si ECHO est allumé, il affiche le prompt.

    You think COMMAND waits for a line. In fact it first asks: are we in the middle of a pipe? a FOR? a .BAT? Only otherwise, and if ECHO is on, does it print the prompt.

    Intermédiaire Intermediate PIPE > FOR > BATCH > clavier

    Ordre explicite dans tcode.asm : PIPEFLAG « has highest presedence » (faute d’orthographe d’origine), puis FORFLAG, puis BATCH. Redirection (RE_INSTR / RE_OUTSTR / RE_OUT_APP pour >>) est remise à zéro avant chaque nouvelle ligne batch.

    Explicit order in tcode.asm: PIPEFLAG “has highest presedence” (original misspelling), then FORFLAG, then BATCH. Redirection (RE_INSTR / RE_OUTSTR / RE_OUT_APP for >>) is cleared before each new batch line.

    Technique Technical GETCOM

    COMTAB

    Découverte Discovery DIR n’est pas un fichier DIR is not a file

    Les commandes « internes » vivent dans le transient. Une table, COMTAB, associe un nom à une routine : DIR, COPY, TYPE, SET, mais aussi CALL, GOTO, IF, FOR, et sous DOS 6 LOADHIGH / LH. Si le nom n’y est pas, on cherche un .COM / .EXE / .BAT sur le disque.

    “Internal” commands live in the transient. A table, COMTAB, maps a name to a routine: DIR, COPY, TYPE, SET, but also CALL, GOTO, IF, FOR, and under DOS 6 LOADHIGH / LH. If the name is not there, we look for a .COM / .EXE / .BAT on disk.

    Intermédiaire Intermediate fCheckDrive · fSwitchAllowed

    Chaque entrée : longueur, nom, drapeaux (le lecteur existe-t-il ? des switches sont-ils permis ?), adresse, messages d’aide. REM pointe sur TCOMMAND — la boucle elle-même : ne rien faire, recommencer. REN et RENAME partagent CRENAME.

    Each entry: length, name, flags (does the drive exist? are switches allowed?), address, help messages. REM points at TCOMMAND — the loop itself: do nothing, start over. REN and RENAME share CRENAME.

    Technique Technical tdata.asm

    Des pipes qui n’en sont pas Pipes that are not pipes

    Découverte Discovery Un fichier au milieu A file in the middle

    Unix lance les deux programmes à la fois. COMMAND.COM n’a pas de vrais pipes : il crée un fichier temporaire, y écrit la sortie du premier programme, puis le donne en entrée au second. D’où la lenteur, et d’où deux noms PIPE1 / PIPE2 qu’on échange.

    Unix runs both programs at once. COMMAND.COM has no real pipes: it creates a temporary file, writes the first program’s output there, then feeds it to the second. Hence the slowness, and two names PIPE1 / PIPE2 that get swapped.

    Intermédiaire Intermediate TEMP= · CreateTempFile

    On cherche TEMP= dans l’environnement. S’il désigne un répertoire (CHMOD, bit 10h), les temporaires y vont. Sinon : répertoire courant, plus la racine — commentaire SR : le nombre d’entrées à la racine est fixe (page FAT). Appel AH=5Ah (déjà vu dans INT 21h), puis CLOSE immédiat pour ne pas « proliferate handles ».

    TEMP= is looked up in the environment. If it names a directory (CHMOD, bit 10h), the temps go there. Otherwise: the current directory, no longer the root — SR comment: the root has a fixed entry count (FAT page). Call AH=5Ah (already on INT 21h), then CLOSE at once so as not to “proliferate handles”.

    AND  [ECHOFLAG], 0FEh

    Pas de prompt au milieu du tuyau. On inverse entrée et sortie pour l’élément suivant.

    No prompt in the middle of the pipe. Input and output are swapped for the next element.

    .BAT

    Découverte Discovery Un fichier lu à la place du clavier A file read instead of the keyboard

    Un batch n’est pas un programme : COMMAND ouvre le fichier, lit une ligne, la traite comme si vous l’aviez tapée, recommence. CALL empile un autre batch (Nest, next_batch). GOTO, IF, FOR, SHIFT vivent dans tbatch*.asm et tfor.asm.

    A batch file is not a program: COMMAND opens the file, reads a line, treats it as if you had typed it, repeats. CALL stacks another batch (Nest, next_batch). GOTO, IF, FOR, SHIFT live in tbatch*.asm and tfor.asm.

    Intermédiaire Intermediate ReadBat · EOF · Free_TPA

    L’état du batch (nom, position, arguments %1…%9) vit dans le résident : le transient peut être rechargé sans perdre AUTOEXEC. En fin de fichier (M037), on nettoie et on revient. Avant un EXEC externe, on peut Free_TPA pour donner le maximum au fils, puis Alloc_TPA (tentative d’aligner sur 64 Ko).

    Batch state (name, position, %1…%9 arguments) lives in the resident: the transient can be reloaded without losing AUTOEXEC. At end of file (M037), we clean up and return. Before an external EXEC, we may Free_TPA to give the child the maximum, then Alloc_TPA (try to align on 64 KB).

    Technique Technical INT 2Fh SHELL · INT 2Eh

    Avant READBAT, un INT 2Fh mult_shell_get demande à un « SHELL » (DOSSHELL) s’il a une ligne à injecter. INT 2Eh, côté résident, exécute une ligne unique (SINGLECOM) — c’est ainsi qu’un programme dit à COMMAND « lance ça » sans relancer tout le .COM.

    Before READBAT, an INT 2Fh mult_shell_get asks a “SHELL” (DOSSHELL) whether it has a line to inject. INT 2Eh, on the resident side, runs a single line (SINGLECOM) — that is how a program tells COMMAND “run this” without relaunching the whole .COM.

    PATH · $EXEC

    Découverte Discovery Le pont vers la page Processus The bridge to the Processes page

    Nom absent de COMTAB : Path_Search (path1.asm) cherche un exécutable ou un .BAT, d’abord ici, puis dans chaque répertoire de PATH=. Le meilleur chemin va dans EXECPATH. Ensuite le résident construit le bloc EXEC0 et appelle INT 21h AH=4Bh — la machine de la page Processus.

    Name not in COMTAB: Path_Search (path1.asm) looks for an executable or a .BAT, first here, then in each PATH= directory. The best path goes into EXECPATH. Then the resident builds the EXEC0 block and calls INT 21h AH=4Bh — the Processes-page machine.

    Intermédiaire Intermediate Handle01 · redirection

    Avant l’EXEC, le résident peut sauver stdin/stdout (Handle01 dans command2.asm) et les rebrancher sur un fichier ou un pipe — c’est le > / < que la page Fichiers décrivait côté SFT. Au retour : restauration, puis ChkSum.

    Before EXEC, the resident may save stdin/stdout (Handle01 in command2.asm) and aim them at a file or a pipe — the > / < the Files page described on the SFT side. On return: restore, then ChkSum.

    Technique Technical BADEXE · reload

    Rev 1.17 (1982) : une erreur de relocation EXE doit revenir au résident, parce que EXELOAD a pu déjà écraser le transient. Le message ComBad (« Invalid COMMAND.COM ») est fatal si on ne peut plus se relire. EXIT interne ne quitte que si ce n’est pas le COMMAND racine (PermCom) — sinon on reste, il n’y a personne au-dessus.

    Rev 1.17 (1982): an EXE relocation error must return to the resident, because EXELOAD may already have overwritten the transient. The ComBad message (“Invalid COMMAND.COM”) is fatal if we can no longer reread ourselves. Internal EXIT leaves only if this is not the root COMMAND (PermCom) — otherwise we stay; there is nobody above.
