cmd/loadfix · exe2bin · printfix · wina20

LOADFIX · EXE2BIN · PRINTFIX · WINA20

Quatre rustines de bord. Charger au-dessus de 64 Ko, aplatir un MZ en .COM, mentir au BIOS imprimante, et un VxD Windows dont on n’a que le binaire. Le DOS 6 est aussi une collection de pansements.

Four edge patches. Load above 64 KB, flatten an MZ into a .COM, lie to the printer BIOS, and a Windows VxD of which we only have the binary. DOS 6 is also a collection of bandages.

Packed file is corrupt

DécouverteDiscovery LOADFIX FOO.EXE

Quand DOS=HIGH, COMMAND réside tout en bas et l’appli se charge parfois sous 64 Ko. Les unpackers EXEPACK de l’époque signent leur décompression et crient « Packed file is corrupt ». LOADFIX s’alloue assez de mémoire pour que le prochain EXEC commence au-dessus du premier segment 1000h.

With DOS=HIGH, COMMAND sits at the bottom and the app sometimes loads under 64 KB. Period EXEPACK unpackers sign their decompression and yell “Packed file is corrupt”. LOADFIX allocates enough memory so the next EXEC starts above the first 1000h paragraph.

IntermédiaireIntermediate CMDSIZE 94h paras

Le résident de COMMAND est chiffré à 94h paragraphes (≈ 2,3 Ko) — la même constante que la page COMMAND. LOADFIX : taille de soi + (1000h − CMDSIZE − soi) si on est encore sous 64 Ko, puis AH=4Ah, puis AH=4Bh du programme demandé, puis AH=4Dh pour renvoyer son errorlevel.

COMMAND’s resident size is hard-coded as 94h paragraphs (≈ 2.3 KB) — the same constant as the COMMAND page. LOADFIX: own size + (1000h − CMDSIZE − self) if still under 64 KB, then AH=4Ah, then AH=4Bh of the requested program, then AH=4Dh to return its errorlevel.

TechniqueTechnical loadfix.asm 
CMDSIZE  equ  94h          ; current resident size of command.com
start:
    mov  ax, offset EndProg
    add  ax, 15
    shr  ax, 4             ; our size in paragraphs
    mov  cx, es
    add  ax, cx            ; top of this program
    sub  ax, 1000h - CMDSIZE
    jae  no_mem            ; already above first 64K
    neg  ax
    add  bx, ax            ; grow so EXEC lands higher
no_mem:
    mov  ah, 4Ah
    int  21h

EXE2BIN

DécouverteDiscovery MZ → image plate

Un .COM n’a pas d’en-tête : CS=DS=SS, IP=100h. GRAPHICS, GRAFTABL, MORE se lient en .EXE puis passent par EXE2BIN. L’outil refuse les relocalisations et les fichiers trop gros pour un segment.

A .COM has no header: CS=DS=SS, IP=100h. GRAPHICS, GRAFTABL, MORE link as .EXE then go through EXE2BIN. The tool refuses relocations and files too big for one segment.

IntermédiaireIntermediate OLDLINK

Équate OLDLINK (off ici) : l’ancien linker mettait son numéro de version là où le nouveau met le nombre d’octets de la dernière page. Si on lit 0004, on force 200h pour prendre la page entière. M001 (27-Dec-90) : plus de test spécial sur les jokers dans le nom.

OLDLINK equate (off here): the old linker put its version number where the new one puts bytes-used-in-last-page. If you read 0004, force 200h to take the whole page. M001 (27-Dec-90): no more special check on wildcards in the name.

TechniqueTechnical e2binit.asm · rev 2.4

« Loader for EXE files under 86-DOS ». Extensions par défaut .EXE → .BIN. Même parseur / messages que le reste de la génération 4. Segment ZLOAD pour l’image à réécrire.

PRINTFIX — bit 3 menteur

DécouverteDiscovery write fault sur LPT

Doug Olson, 30-Aug-91. Certains BIOS rendent le bit 3 du statut imprimante (I/O error) levé alors que ça imprime. DOS 5 a commencé à le croire → write fault. PRINTFIX crochète INT 17h et, pour AH=02h (get status), rend 90h (selected + not busy) sans même appeler le BIOS.

Doug Olson, 30-Aug-91. Some BIOSes return printer status bit 3 (I/O error) set even though printing works. DOS 5 started believing it → write fault. PRINTFIX hooks INT 17h and, for AH=02h (get status), returns 90h (selected + not busy) without even calling the BIOS.

IntermédiaireIntermediate uniquement les PC malades

Le commentaire insiste : « should only be installed on systems that exhibit the I/O error problem ». Sur une machine saine, on masque de vraies pannes.

The comment insists: “should only be installed on systems that exhibit the I/O error problem”. On a healthy machine you hide real faults.

TechniqueTechnical printfix.asm 
patch proc near
    pushf
    cmp  ah, 02h          ; Get Printer Status?
    jne  call_old
    mov  ah, 90h          ; bit4 selected, bit7 not busy
    popf
    iret
call_old:
    popf
    pushf
    call [old_int_17_addr]
    iret

Pour AH≠02h (init, out char) on appelle l’ancien handler — on ne ment que sur le statut. Le résident tient dans quelques dizaines d’octets.

For AH≠02h (init, out char) the old handler is called — we only lie about status. The resident is a few dozen bytes.

WINA20.386

DécouverteDiscovery binaire seul

cmd/wina20/ ne contient que wina20.386 et un makefile qui le copie / compresse. C’est le VxD Windows 3.x qui empêche HIMEM d’éteindre A20 pendant que Windows tourne — le pendant noyau de la page HIMEM (« les applis copy-protected veulent A20 éteint »).

cmd/wina20/ holds only wina20.386 and a makefile that copies / compresses it. It is the Windows 3.x VxD that stops HIMEM turning A20 off while Windows runs — the kernel-side counterpart of the HIMEM page (“copy-protected apps want A20 off”).

IntermédiaireIntermediate pourquoi dans cmd/ ?

Livré sur la disquette DOS, pas dans Windows. HIMEM et Windows 3.0 se battaient pour A20 ; le VxD est le cessez-le-feu. Sans source, on le range avec les rustines, pas avec EMM386.

Shipped on the DOS disk, not inside Windows. HIMEM and Windows 3.0 fought over A20; the VxD is the cease-fire. With no source, it sits with the patches, not with EMM386.

TechniqueTechnical wina20.38_

Le makefile produit la forme compressée Setup (wina20.38_) — même pipeline EXPAND que HIMEM.SY_.
