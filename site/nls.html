Clavier et pays Keyboard and country

DOS est né en anglais. KEYB, COUNTRY.SYS et NLSFUNC y greffent AZERTY, dates jj/mm/aaaa, et pages de codes. COMMAND appelle déjà INT 21h AH=38h à chaque boucle pour rafraîchir INTERNATVARS.

DOS was born in English. KEYB, COUNTRY.SYS and NLSFUNC graft on AZERTY, dd/mm/yyyy dates, and code pages. COMMAND already calls INT 21h AH=38h every loop to refresh INTERNATVARS.

KEYB

DécouverteDiscovery KEYB FR

Le BIOS livre un clavier US. KEYB s’accroche à INT 9 / INT 16 et traduit les scan codes. Alt+chiffres du pavé restent le moyen universel d’entrer un caractère.

The BIOS ships a US keyboard. KEYB hooks INT 9 / INT 16 and translates scan codes. Alt+keypad digits stay the universal way to enter a character.

IntermédiaireIntermediate dev/keyboard · cmd/keyb

Des tables par pays (dizaines de .asm). KEYB.COM charge la bonne. CHCP (interne COMMAND, tcmd2b.asm) change la page de codes active — il faut NLSFUNC et DISPLAY.SYS / CON.

Per-country tables (dozens of .asm files). KEYB.COM loads the right one. CHCP (COMMAND internal, tcmd2b.asm) switches the active code page — you need NLSFUNC and DISPLAY.SYS / CON.

TechniqueTechnical DBCS

ITESTKANJ dans le résident de COMMAND : un caractère peut occuper deux octets (japonais). PATH et TransPath ont des branches DBCS. rucode.asm le mentionne.

ITESTKANJ in COMMAND’s resident: a character may occupy two bytes (Japanese). PATH and TransPath have DBCS branches. rucode.asm mentions it.

COUNTRY.SYS

DécouverteDiscovery AH=38h · AH=65h

Séparateur décimal, format de date, symbole monétaire, table de collation pour SORT. CONFIG.SYS : COUNTRY=033,850,C:\DOS\COUNTRY.SYS.

Decimal separator, date format, currency symbol, collation table for SORT. CONFIG.SYS: COUNTRY=033,850,C:\DOS\COUNTRY.SYS.

IntermédiaireIntermediate $INTERNATIONAL · $GetExtCntry

Dans la table DISPATCH : 38h et 65h/66h (code page). DATE/TIME internes de COMMAND (tpipe.asm) s’en servent pour afficher jj-mm-aa vs mm-dd-yy.

In the DISPATCH table: 38h and 65h/66h (code page). COMMAND’s DATE/TIME internals (tpipe.asm) use them to show dd-mm-yy vs mm-dd-yy.

TechniqueTechnical dev/country

COUNTRY.SYS est un fichier de données + un petit driver. NLSFUNC.EXE le rend résident pour CHCP à chaud.

437 · 850 · 863

DécouverteDiscovery Le même octet, un autre glyphe The same byte, another glyph

Un fichier texte n’a pas de « encoding » déclaré. MODE CON CP PREP + CHCP change l’écran et le clavier. GRAFTABL charge les glyphes graphiques.

A text file has no declared encoding. MODE CON CP PREP + CHCP changes the screen and keyboard. GRAFTABL loads the graphic glyphs.

IntermédiaireIntermediate DIR_CODEPG

DOS 4 a prévu une page de codes dans l’entrée répertoire (dirent.inc). Peu d’outils s’en servent. Le mismatch code page peut faire échouer un OPEN (hooks dans $Open).

DOS 4 reserved a code page in the directory entry (dirent.inc). Few tools use it. A code-page mismatch can fail an OPEN (hooks in $Open).
