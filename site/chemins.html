Chemins menteurs Lying paths

Quatre utilitaires qui trichent avant TransPath : une lettre qui est un dossier, deux lecteurs fusionnés, A: qui veut dire B:, et un PATH pour les données. Le noyau a des CDS (Current Directory Structure) exprès pour ça.

Four utilities that cheat before TransPath: a letter that is a folder, two drives fused, A: meaning B:, and a PATH for data. The kernel has CDS (Current Directory Structure) just for this.

SUBST E: C:\PROJETS

DécouverteDiscovery Une lettre pour un dossier trop profond A letter for a folder that is too deep

Les vieux programmes n’aiment pas les chemins longs. SUBST leur donne E: qui est en réalité C:\PROJETS. DIR E: marche. FORMAT E: serait une catastrophe — d’où les interdits.

Old programs dislike long paths. SUBST gives them E: that is really C:\PROJETS. DIR E: works. FORMAT E: would be a disaster — hence the bans.

IntermédiaireIntermediate CDS

inc/curdir.inc : une entrée par lettre jusqu’à LASTDRIVE. SUBST écrit le chemin réel et pose un flag « join/subst ». TransPath développe avant d’ouvrir.

inc/curdir.inc: one entry per letter up to LASTDRIVE. SUBST writes the real path and sets a “join/subst” flag. TransPath expands it before opening.

TechniqueTechnical cmd/subst

Petit utilitaire C/ASM qui appelle INT 21h AH=60h ($NameTrans) et les fonctions CDS. LASTDRIVE= doit être assez grand pour qu’il reste une lettre libre.

JOIN et ASSIGN

DécouverteDiscovery JOIN D: C:\D

JOIN inverse SUBST : un lecteur physique apparaît comme un sous-dossier. ASSIGN A=B : les appels à A: vont sur B: — rustine pour les programmes qui n’ont que A: en tête.

JOIN inverts SUBST: a physical drive appears as a subfolder. ASSIGN A=B: calls to A: go to B: — a patch for programs that only know A:.

IntermédiaireIntermediate incompatibles

BACKUP, FORMAT, DISKCOPY, JOIN, SUBST se refusent mutuellement. Le manuel et le code testent les flags CDS avant d’accepter.

BACKUP, FORMAT, DISKCOPY, JOIN, SUBST refuse one another. The manual and the code test CDS flags before accepting.

TechniqueTechnical assign.asm

ASSIGN est un TSR qui patch la table de traduction des lecteurs très tôt (avant même le CDS parfois). Plus brutal que SUBST. Microsoft a fini par le déconseiller.

APPEND

DécouverteDiscovery APPEND C:\DATA

PATH trouve les .COM. APPEND fait la même chose pour les données : OPEN de FOO.DAT cherche dans C:\DATA si le fichier n’est pas ici. Les bases DOS 2.x en avaient besoin.

PATH finds .COM files. APPEND does the same for data: opening FOO.DAT searches C:\DATA if the file is not here. DOS 2.x databases needed it.

IntermédiaireIntermediate /X /E

/X : APPEND agit aussi sur les recherches (FindFirst). /E : la liste vit dans l’environnement. COMMAND a un APPEND_EXEC et un PDB_Append « not sure if still used ».

/X: APPEND also acts on searches (FindFirst). /E: the list lives in the environment. COMMAND has APPEND_EXEC and a PDB_Append “not sure if still used”.

TechniqueTechnical INT 2Fh APPEND

TSR multiplex. TransPath / DOS_Open demandent à APPEND un chemin étendu. Risque : on ouvre le mauvais FOO.DAT. Les manuels crient « ne pas mélanger avec SUBST ».
