dev/emm386/ · CEMM

EMM386

Le cousin de HIMEM : un 386 en mode V86 qui fabrique de la mémoire paginée (EMS) et les UMB entre 640 Ko et 1 Mo. Le dépôt s’appelle encore CEMM — Compaq Expanded Memory Manager, 1986.

HIMEM’s cousin: a 386 in V86 mode that builds paged memory (EMS) and UMBs between 640 KB and 1 MB. The tree is still named CEMM — Compaq Expanded Memory Manager, 1986.

Mode V86

DécouverteDiscovery DOS croit être en réel, le 386 mappe DOS thinks it is real-mode; the 386 maps

Sans ça, les adresses 640K–1M sont des ROM. EMM386 pose des pages RAM à la place (fenêtres EMS, UMB). DOS et les programmes 16 bits continuent comme si de rien n’était.

Without it, 640K–1M is ROM. EMM386 maps RAM pages there instead (EMS windows, UMBs). DOS and 16-bit programs carry on as if nothing happened.

IntermédiaireIntermediate DMA · A20 · I/O traps

Le DMA ne connaît pas la pagination : dmatrap.asm, dmaserv.asm. A20 est aussi piégé (a20trap.asm) — HIMEM et EMM386 doivent se parler (xms.asm). iotrap.asm, pictrap.asm : ports et interruptions.

DMA does not know paging: dmatrap.asm, dmaserv.asm. A20 is trapped too (a20trap.asm) — HIMEM and EMM386 must talk (xms.asm). iotrap.asm, pictrap.asm: ports and IRQs.

TechniqueTechnical .386p · i386.asm

Le module s’assemble en .386p. modesw.asm / retreal.asm : aller-retour réel ↔ V86. lhvxd/ : un VxD loadhi pour Windows.

The module assembles as .386p. modesw.asm / retreal.asm: real ↔ V86. lhvxd/: a loadhi VxD for Windows.

EMS et UMB

DécouverteDiscovery Deux cadeaux d’une même machine Two gifts from one machine

EMS : une fenêtre (souvent D000) où l’on fait défiler des pages de 16 Ko — les vieux jeux. UMB : des blocs stables que DOS enchaîne (HIGH_FIRST, DEVICEHIGH).

EMS: a window (often D000) through which 16 KB pages scroll — old games. UMBs: stable blocks DOS chains (HIGH_FIRST, DEVICEHIGH).

IntermédiaireIntermediate emm40.asm · umbseg.asm

EMS 4.0 dans emm40.asm / emmfunct.asm. Les UMB sont exposées via XMS aussi. Il faut HIMEM avant EMM386 dans CONFIG.SYS.

EMS 4.0 lives in emm40.asm / emmfunct.asm. UMBs are also exposed via XMS. HIMEM must come before EMM386 in CONFIG.SYS.

TechniqueTechnical INT 67h

L’API EMS historique est INT 67h, distincte de INT 21h et de XMS (INT 2Fh). emm.asm est l’interface.

VCPI · Windows

DécouverteDiscovery Laisser un autre prendre le 386 Let someone else take the 386

DOS extenders (DOS/4GW, etc.) veulent le mode protégé. VCPI (vcpi.asm) est le protocole pour « emprunter » le processeur à EMM386. Windows a ses propres modules winemm.asm, winsrch.asm.

DOS extenders (DOS/4GW, etc.) want protected mode. VCPI (vcpi.asm) is the protocol to “borrow” the CPU from EMM386. Windows has its own winemm.asm, winsrch.asm.

IntermédiaireIntermediate NOEMS

Souvent on charge EMM386 avec NOEMS : pas de fenêtre EMS, seulement des UMB pour LOADHIGH. Moins de conflits avec Windows 3.1 en mode 386.

Often EMM386 is loaded with NOEMS: no EMS window, only UMBs for LOADHIGH. Fewer clashes with Windows 3.1 in 386 mode.

TechniqueTechnical except.asm

Les fautes de page / exceptions 386 sont dans except.asm, errhndlr.asm. Un programme réel qui touche un port piégé réveille EMM386 — d’où la lenteur parfois visible.

386 page faults / exceptions live in except.asm, errhndlr.asm. A real-mode program touching a trapped port wakes EMM386 — hence the occasional slowness.
