bios/msint13.asm · bios/msdisk.asm

INT 13h

Sous la FAT, sous les tampons DOS, sous SMARTDRV : le BIOS disque. IO.SYS l’enveloppe — media check, BPB, retries — puis appelle l’INT 13h d’origine. FIGREC produit un secteur ; INT 13h le lit en CHS.

Under FAT, under DOS buffers, under SMARTDRV: the disk BIOS. IO.SYS wraps it — media check, BPB, retries — then calls the original INT 13h. FIGREC yields a sector; INT 13h reads it in CHS.

BDS

DécouverteDiscovery La fiche « physique » du lecteur The drive’s “physical” card

Le DPB est l’affaire de DOS (FAT). Le BDS (BIOS Data Structure, msbds.inc) est l’affaire d’IO.SYS : têtes, secteurs/piste, dernier média, pointeur de BPB. Beaucoup de routines gardent ES:DI sur le BDS courant — « standard operating environment ».

The DPB is DOS’s affair (FAT). The BDS (BIOS Data Structure, msbds.inc) is IO.SYS’s: heads, sectors/track, last media, BPB pointer. Many routines keep ES:DI on the current BDS — “standard operating environment”.

IntermédiaireIntermediate msdisk.asm

C’est ici que naît le BPB quand le boot n’en a pas (disquette exotique). Media descriptor, changement de disque : FATREAD_CDS interroge ce niveau.

This is where a BPB is born when the boot has none (odd floppy). Media descriptor, disk change: FATREAD_CDS asks this layer.

TechniqueTechnical HIDDENSECTORS

Les secteurs cachés du BPB (partition) se traduisent ici en CHS + numéro de lecteur BIOS (80h = premier dur). FDISK a écrit ces nombres ; FORMAT les a copiés dans le boot.

The BPB’s hidden sectors (partition) become CHS + BIOS unit (80h = first hard disk) here. FDISK wrote those numbers; FORMAT copied them into the boot.

call_orig13

DécouverteDiscovery Ne pas se rappeler soi-même Do not call yourself

IO.SYS a pris INT 13h. Pour parler au vrai BIOS, il faut l’ancien vecteur : call_orig13 (M030). SMARTDRV fait la même chose un étage plus haut.

IO.SYS took INT 13h. To talk to the real BIOS you need the old vector: call_orig13 (M030). SMARTDRV does the same one level up.

IntermédiaireIntermediate Retries · reset

Erreur disque : reset contrôleur, réessayer, puis INT 24. Les disquettes ont plus de retries que le dur. C’est ici que « Abort, Retry » naît vraiment.

Disk error: reset the controller, retry, then INT 24. Floppies get more retries than the hard disk. This is where “Abort, Retry” is really born.

TechniqueTechnical RPL M056

Le chargeur réseau (RPL) installe un faux INT 13. SYSINIT et le transient de COMMAND ne doivent pas l’écraser — déjà noté dans msload / sysinit.

Windows · HMA

DécouverteDiscovery win386.inc

Windows 386 veut connaître les lecteurs et parfois reloger des buffers. msint13.asm inclut win386.inc et parle aussi à la HMA (multMULTGETHMAPTR).

Windows 386 wants to know the drives and sometimes relocate buffers. msint13.asm includes win386.inc and also talks to the HMA (multMULTGETHMAPTR).

IntermédiaireIntermediate INT 2Fh 4Ah

Multiplex 4Ah : pointeur HMA, allocation HMA — le même monde que HIMEM, vu depuis le BIOS DOS.

Multiplex 4Ah: HMA pointer, HMA allocation — the same world as HIMEM, seen from the DOS BIOS.

TechniqueTechnical CHS 1024

INT 13h classique : 10 bits de cylindre → 1024. Au-delà, le BIOS « étend » ou ment. DOS 6 n’a pas INT 13h extensions. Les gros disques passent par la géométrie traduite dans le BDS / les hidden sectors.

Classic INT 13h: 10 bits of cylinder → 1024. Beyond that the BIOS “extends” or lies. DOS 6 has no INT 13h extensions. Large disks go through geometry translated in the BDS / hidden sectors.
