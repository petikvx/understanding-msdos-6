cmd/debug/debug.asm

DEBUG

L’outil pour appeler INT 21h à la main, voir un PSP, patcher un octet. C’est le laboratoire des autres pages : A assemble, U désassemble, G saute dans FOO.COM comme $EXEC.

The tool to fire INT 21h by hand, see a PSP, patch a byte. It is the lab for the other pages: A assembles, U disassembles, G jumps into FOO.COM like $EXEC.

Un mini langage

DécouverteDiscovery -U 100

Dump, assemble, trace, go, register, compare, fill, search, hex arithmetic. Chaque commande est un petit interpréteur dans debcom1/2/3.asm.

Dump, assemble, trace, go, register, compare, fill, search, hex arithmetic. Each command is a small interpreter in debcom1/2/3.asm.

IntermédiaireIntermediate debasm · debuasm

Assembleur et désassembleur 8086 maison — pas MASM. Assez pour écrire MOV AH,3D / INT 21 et voir AX au retour. C’est ainsi qu’on vérifiait la page Fichiers avant qu’elle existe.

A home-grown 8086 assembler and disassembler — not MASM. Enough to write MOV AH,3D / INT 21 and see AX on return. That is how you would have checked the Files page before it existed.

TechniqueTechnical INT 3 · TF

Trace pose le trap flag ; les breakpoints sont INT 3. DEBUG est lui-même un processus avec un PSP : il EXEC le programme cible et reprend la main sur INT 3 / INT 1.

Charger sans COMMAND

DécouverteDiscovery N FOO.COM · L · G

Name + Load : lit le fichier au CS:100 comme un COM, ou applique le header MZ. Go lance. Moins de cérémonie que COMMAND, même $EXEC en dessous parfois, parfois lecture brute.

Name + Load: reads the file at CS:100 like a COM, or applies the MZ header. Go runs it. Less ceremony than COMMAND, sometimes the same $EXEC underneath, sometimes a raw read.

IntermédiaireIntermediate W · E

Write peut réécrire le binaire. Enter patche la mémoire. C’est l’outil avec lequel on a « fixé » des COM en attendant un vrai linker.

Write can rewrite the binary. Enter patches memory. That is the tool people used to “fix” COMs while waiting for a real linker.

TechniqueTechnical sysver.inc

Des variantes sysver.tru / .fal : DEBUG ment parfois sur la version (encore SETVER, vu de l’intérieur de l’outil).

EMS

DécouverteDiscovery debems.asm

DEBUG sait afficher / allouer de l’EMS (INT 67h). Utile pour tester EMM386 sans écrire un programme.

DEBUG can display / allocate EMS (INT 67h). Handy to test EMM386 without writing a program.

IntermédiaireIntermediate XA · XD · XM

Les commandes X* parlent à la page EMM386. Sans gestionnaire, elles échouent proprement.

The X* commands talk to the EMM386 page. Without a manager they fail cleanly.

TechniqueTechnical debcom*.asm

Découpage historique : COM1 I/O mémoire, COM2 exécution, COM3 disque. Un DEBUG est un petit DOS dans le DOS.
