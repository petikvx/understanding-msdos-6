dev/ramdrive/ramdrive.asm

RAMDRIVE.SYS

Un disque qui n’en est pas un : le driver fabrique un BPB, une FAT, une racine, et sert les secteurs depuis la XMS, l’EMS ou la mémoire conventionnelle. DOS y voit un FAT12/16 normal.

A disk that is not one: the driver builds a BPB, a FAT, a root, and serves sectors from XMS, EMS or conventional memory. DOS sees a normal FAT12/16.

device = ramdrive.sys

DécouverteDiscovery [bbbb] [ssss] [dddd]

Taille en Ko (défaut 64, min 4, max 32767), taille de secteur (128–1024, max 512 sous IBM PC DOS), nombre d’entrées racine (défaut 64). Si la RAM manque, on retombe à 16 entrées racine.

Size in KB (default 64, min 4, max 32767), sector size (128–1024, max 512 under IBM PC DOS), root entries (default 64). If RAM is short, it falls back to 16 root entries.

IntermédiaireIntermediate VOLID

Le commentaire exige de changer la date de volume à chaque version du driver. C’est une entrée ATTR_VOLUME_ID dans la racine — page DIR_ENTRY.

The comment insists the volume date change with every driver version. That is an ATTR_VOLUME_ID root entry — DIR_ENTRY page.

TechniqueTechnical dirent.inc local

Le driver embarque sa copie de dirent.inc et de devsym.inc : il construit le volume tout seul, sans appeler FORMAT. Au reboot, tout disparaît.

/E · /A · conventionnel

DécouverteDiscovery Trois endroits pour les octets Three places for the bytes

/E : XMS (HIMEM). /A : Above Board / EMS. Rien : mémoire basse — on vole de la TPA, mauvais pour FOO.COM.

/E: XMS (HIMEM). /A: Above Board / EMS. Neither: low memory — it steals TPA, bad for FOO.COM.

IntermédiaireIntermediate xmm.inc · emm.inc

Même couple XMS/EMS qu’EMM386. Sans HIMEM, /E échoue et le driver ne s’installe pas. Above Board est l’ancêtre matériel de l’EMS.

Same XMS/EMS pair as EMM386. Without HIMEM, /E fails and the driver does not install. Above Board is EMS’s hardware ancestor.

TechniqueTechnical loadall.inc

Sur 286, la copie vers l’extended memory passait parfois par l’instruction LOADALL (non documentée). Le fichier est encore là.

Un FAT comme les autres

DécouverteDiscovery DIR E:

CHKDSK, COPY, COMMAND traitent E: comme C:. Seul le driver sait que « secteur 10 » est un offset dans un bloc XMS.

CHKDSK, COPY, COMMAND treat E: like C:. Only the driver knows “sector 10” is an offset in an XMS block.

IntermédiaireIntermediate media byte

Le descripteur média est choisi pour ressembler à une disquette (souvent F8/F0). IsEOF et le cas 0FF0h (page FAT) existent aussi pour ces volumes.

The media descriptor is chosen to look like a floppy (often F8/F0). IsEOF and the 0FF0h case (FAT page) apply to these volumes too.

TechniqueTechnical INIT overlay

Comme tout DEVICE=, l’init calcule la taille résidente (petit stub + BPB) et rend le reste. Les mégaoctets XMS ne sont pas dans l’arène DOS.
