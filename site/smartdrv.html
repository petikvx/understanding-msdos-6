dev/smartdrv/ · bambi.asm

SMARTDRV

Le cache disque de DOS 6. Dans le dépôt, il s’appelle Bambi. Il se glisse sous INT 13h, garde les secteurs chauds en XMS, et écrit plus tard — d’où le message « waiting for cache » à l’arrêt.

DOS 6’s disk cache. In the tree it is named Bambi. It slips under INT 13h, keeps hot sectors in XMS, and writes later — hence “waiting for cache” at shutdown.

Bambi

DécouverteDiscovery Un cache, pas un système de fichiers A cache, not a file system

SMARTDRV ne comprend pas FAT. Il voit des secteurs. Relire le même cluster (page FAT) devient une copie XMS. Windows 3.1 a un VxD jumeau (sdvxd/).

SMARTDRV does not understand FAT. It sees sectors. Rereading the same cluster (FAT page) becomes an XMS copy. Windows 3.1 has a twin VxD (sdvxd/).

Accrocher INT 13

DécouverteDiscovery Sous le BIOS, au-dessus du métal Under the BIOS, above the metal

hooks.asm prend INT 13h (et parfois 2Fh). IO.SYS a déjà le sien (page INT 13) : la chaîne devient programme → SMARTDRV → IO.SYS → ROM.

hooks.asm takes INT 13h (and sometimes 2Fh). IO.SYS already has its own (INT 13 page): the chain is program → SMARTDRV → IO.SYS → ROM.

IntermédiaireIntermediate logphys.asm

Il faut distinguer lecteur logique DOS et unité BIOS. get_dpb.asm relie au DPB. Un cache trop zélé sur une disquette changeante est un désastre — d’où les options /X et le media check.

Logical DOS drive and BIOS unit must be told apart. get_dpb.asm ties to the DPB. A too-eager cache on a changing floppy is a disaster — hence /X and media check.

TechniqueTechnical reboot.asm

Au reboot, il faut vider le cache sale. reboot.asm / dirtywrt.asm. Ctrl-Alt-Del sans flush = FAT incohérente — CHKDSK au suivant.

On reboot the dirty cache must be flushed. reboot.asm / dirtywrt.asm. Ctrl-Alt-Del without a flush = inconsistent FAT — CHKDSK next time.

Écriture différée

DécouverteDiscovery Plus vite, plus risqué Faster, riskier

Write-behind : COPY rend la main avant que le disque ait tout. Coupure de courant = clusters à moitié écrits. D’où le cache en lecture seule sur les disquettes par défaut.

Write-behind: COPY returns before the disk has everything. Power loss = half-written clusters. Hence read-only cache on floppies by default.

IntermédiaireIntermediate dirtywrt.asm

Le noyau a déjà buf_dirty (page FAT). SMARTDRV est un deuxième étage, plus gros, en XMS. Les deux peuvent coexister ; BUFFERS= petit suffit alors.

The kernel already has buf_dirty (FAT page). SMARTDRV is a second, larger tier in XMS. Both can coexist; a small BUFFERS= is then enough.
