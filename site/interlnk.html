c6ers/interlnk/ · FastLynx

Interlnk

Deux PC, un câble, les lecteurs de l’un apparaissent sur l’autre. Le client est un driver bloc (comme RAMDRIVE) ; le serveur (INTERSVR) exécute les requêtes. Dans le dépôt, une partie s’appelle encore FastLynx.

Two PCs, one cable, one machine’s drives appear on the other. The client is a block driver (like RAMDRIVE); the server (INTERSVR) runs the requests. In the tree, part of it is still called FastLynx.

DEVICE=INTERLNK.EXE

DécouverteDiscovery E: = C: du portable

COPY E:\AUTOEXEC.BAT C:\ marche. FAT, SFT, COMMAND ne savent pas que les secteurs traversent un câble. Seul le driver client le sait.

COPY E:\AUTOEXEC.BAT C:\ works. FAT, SFT, COMMAND do not know the sectors cross a cable. Only the client driver does.

IntermédiaireIntermediate main.c · intersvr

Le serveur est un programme (pas un DEVICE=) qui monopolise la machine : boucle, CRC, écran de statut (percent.asm). Le client, lui, est chargé tôt pour que E: existe au moment de COMMAND.

The server is a program (not DEVICE=) that owns the machine: loop, CRC, status screen (percent.asm). The client is loaded early so E: exists by the time COMMAND starts.

TechniqueTechnical int2f.asm

Multiplex pour cloner le serveur sur le client (clone.c) : on envoie INTERSVR.EXE par le câble la première fois. Installation sans disquette.

Deux fils

DécouverteDiscovery serial.asm · parallel.asm

Série (null modem) plus lent, plus long. Parallèle (câble Interlnk) plus vite. Le même protocole, deux transports dans fxlib/.

Serial (null modem) slower, longer. Parallel (Interlnk cable) faster. Same protocol, two transports in fxlib/.

IntermédiaireIntermediate crctab.asm

Chaque paquet a un CRC. Un octet perdu sur 3 mètres de série, et la FAT distante serait pourrie. sendrecv.asm / listen.asm : timeout et retry — version câble d’INT 13 retries.

Each packet has a CRC. One lost byte on 3 metres of serial and the remote FAT would rot. sendrecv.asm / listen.asm: timeout and retry — a cable version of INT 13 retries.

TechniqueTechnical printer.asm

On peut aussi rediriger PRN vers l’imprimante de l’autre machine. Client bloc + client caractère. IOCTL traverse le câble.

Un BDS lointain

DécouverteDiscovery driver/block.asm

Le client implémente les stratégies d’un block device : init, media check, build BPB, read, write. SYSINIT le traite comme RAMDRIVE. Le BPB vient du serveur.

The client implements a block device’s strategies: init, media check, build BPB, read, write. SYSINIT treats it like RAMDRIVE. The BPB comes from the server.

IntermédiaireIntermediate criterr.c

INT 24 côté serveur si le portable n’a plus de batterie / câble débranché. Le client voit une erreur disque classique — Abort, Retry.

INT 24 on the server if the laptop dies / cable unplugged. The client sees a classic disk error — Abort, Retry.

TechniqueTechnical packets.h

Les paquets décrivent les RH (request headers) DOS sérialisés. Un READ de 1 secteur = un aller-retour. SMARTDRV sur le client aide beaucoup.
