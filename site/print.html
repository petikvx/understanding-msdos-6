cmd/print/print_r.asm · print_t.asm

PRINT

Le spouleur : même architecture que COMMAND.COM — un résident qui imprime pendant que vous travaillez, un transient pour PRINT fichier.txt. Il vole des tranches de temps sur INT 28 (idle) et doit pouvoir appeler AH=59h depuis un INT 24.

The spooler: same architecture as COMMAND.COM — a resident that prints while you work, a transient for PRINT file.txt. It steals time slices on INT 28 (idle) and must be able to call AH=59h from INT 24.

Deux moitiés

DécouverteDiscovery print_r · print_t

Le premier lancement installe le résident et reste. Les suivants ne font que passer des noms de fichiers au TSR via INT 2Fh. TransSize / TransRet mesurent la partie jetable.

The first launch installs the resident and stays. Later ones only pass file names to the TSR via INT 2Fh. TransSize / TransRet measure the disposable part.

IntermédiaireIntermediate STDPRN

La sortie va au handle 4 (STDPRN) ou à un device donné (/D:). IOCTL peut passer PRN en raw pour ne pas interpréter les tabs.

Output goes to handle 4 (STDPRN) or a given device (/D:). IOCTL can put PRN in raw so tabs are not interpreted.

TechniqueTechnical print_rm / print_tm

Les fichiers *_rm / *_tm sont les messages. pridefs.inc : structures de la file. Même idée RES/TRAN que COMMAND, à plus petite échelle.

INT 28 · idle

DécouverteDiscovery Imprimer quand DOS s’ennuie Print when DOS is bored

Quand COMMAND attend une touche, DOS émet INT 28. PRINT en profite pour envoyer un caractère à l’imprimante. Le dispatcher coupe INT 28 sur DskStack (IdleInt=0) : pas d’impression au milieu d’un WRITE disque.

When COMMAND waits for a key, DOS issues INT 28. PRINT uses that to send a character to the printer. The dispatcher turns INT 28 off on DskStack (IdleInt=0): no printing in the middle of a disk WRITE.

IntermédiaireIntermediate M001 retiré

5/31/91 : on avait ajouté le spool aussi sur les idle INT 2Fh. 8/5/91 : retiré pour DOS 5, « à remettre dans une version future ». DOS 6 livre encore le retrait.

31 May 91: spooling was also added on INT 2Fh idles. 5 Aug 91: backed out for DOS 5, “reinstate in a future version”. DOS 6 still ships the pull-out.

TechniqueTechnical SPOOLINT

msctrlc.asm exporte SPOOLINT. PRINT + INT 24 : GetExtendedError doit rester sur AuxStack — déjà commenté dans le dispatcher.

La file

DécouverteDiscovery /Q · /T · /C

Une liste de noms, un fichier en cours. /T vide tout, /C annule le courant. Le résident ouvre les fichiers lui-même (handles) pendant que vous êtes dans EDIT.

A list of names, one file in progress. /T clears all, /C cancels the current. The resident opens the files itself (handles) while you sit in EDIT.

IntermédiaireIntermediate InDos

PRINT regarde InDos avant d’appeler le noyau. Réentrer dans INT 21h au mauvais moment = pile détruite. D’où INT 28 seulement quand DOS est « idle-but-safe ».

PRINT looks at InDos before calling the kernel. Re-entering INT 21h at the wrong time = smashed stack. Hence INT 28 only when DOS is “idle-but-safe”.

TechniqueTechnical A002 LPT3

PTM : DIR > LPT3 se bloquait — msctrlc A002. Les redirections vers un spouleur et PRINT lui-même se marchaient dessus.
