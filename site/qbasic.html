45/ — pas cmd/qbasic/

QBasic

L’interpréteur livré avec DOS 6. cmd/qbasic/ n’a que l’EXE compressé et les démos. Le source tient dans 45/ — un nom court pour la ligne de commande DOS de 128 caractères (BenS, 16-Mar-1992).

The interpreter shipped with DOS 6. cmd/qbasic/ only has the packed EXE and the demos. The source lives in 45/ — a short name for DOS’s 128-character command line (BenS, 16-Mar-1992).

Deux tiroirs

DécouverteDiscovery binaires vs QBI

Setup pose QBASIC.EXE, GORILLA.BAS, NIBBLES.BAS. Pour lire le parseur, le scanner et les exécuteurs : 45/qb/ir/ (Quick Basic Interpreter). L’UI et l’init DOS 6 : 45/qb5/.

Setup drops QBASIC.EXE, GORILLA.BAS, NIBBLES.BAS. To read the parser, scanner and executors: 45/qb/ir/ (Quick Basic Interpreter). UI and DOS 6 init: 45/qb5/.

IntermédiaireIntermediate héritage QB 4.5

Les sources viennent du groupe QuickBASIC. QBasic 1.1 est un interpréteur sans compilateur : pas de .EXE produit, pas de user-libraries (commentaire dans uifileio.asm : retirées « to keep » le binaire petit).

The sources come from the QuickBASIC group. QBasic 1.1 is an interpreter with no compiler: no produced .EXE, no user-libraries (comment in uifileio.asm: removed “to keep” the binary small).

Parse, scan, execute

DécouverteDiscovery prs* ss* ex*

Une ligne BASIC devient du p-code. prs*.asm parse, ss*.asm scanne / type-check, ex*.asm exécute (exfor, exif, exprint, exgraph…). Le texte source vit dans le text manager (txt*.asm).

A BASIC line becomes p-code. prs*.asm parses, ss*.asm scans / type-checks, ex*.asm executes (exfor, exif, exprint, exgraph…). Source text lives in the text manager (txt*.asm).

IntermédiaireIntermediate init.asm

Point d’entrée : 45/qb5/ir/init.asm — « initial entry point to QBI ». Parse la ligne de commande (cmdSwitches, /RUN, /EDCOM, /QHELP).

Entry: 45/qb5/ir/init.asm — “initial entry point to QBI”. Parses the command line (cmdSwitches, /RUN, /EDCOM, /QHELP).

TechniqueTechnical BNF 
; 45/qb5/ir/init.asm
;Purpose: This module contains the initial entry point to QBI.
        includeOnce     parser
        includeOnce     executor
cbmaxTOPIC equ 40          ; [QH1] max topic for Dos6 QHelp

La grammaire est qbasbnf.prs. Le premier NMAKE peut échouer faute de RAM pour les tables ; le second passe par un .BAT. Avec 561 Ko libres ça passe du premier coup (Compaq 386/33, ~1 min 45).

The grammar is qbasbnf.prs. The first NMAKE may fail for lack of RAM for the tables; the second goes through a .BAT. With 561 KB free it works first time (Compaq 386/33, ~1 min 45).

SAMPLE

DécouverteDiscovery \45\QB5\QBAS

cd \45\QB5\QBAS puis SAMPLE produit QBASIC.EXE, EDIT.COM, HELP.COM et les .HLP. Destinés au répertoire DOS par Setup.

cd \45\QB5\QBAS then SAMPLE produces QBASIC.EXE, EDIT.COM, HELP.COM and the .HLPs. Setup puts them in the DOS directory.

IntermédiaireIntermediate COW

Les fenêtres, menus, boîtes : COW (45/beef/cw/), le même toolkit que DOSSHELL. Deux libs : cow.lib et cowtandy.lib.

Windows, menus, boxes: COW (45/beef/cw/), the same toolkit as DOSSHELL. Two libs: cow.lib and cowtandy.lib.
