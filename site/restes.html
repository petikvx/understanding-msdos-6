ADDDRV : DEVICE= sans reboot

DécouverteDiscovery ADDDRV mon.cfg

Sur les DOS japonais (préfixes MSKK, 1987–1991), on peut charger un pilote après l’invite. Le fichier passé à ADDDRV est un mini-CONFIG : lignes DEVICE= et DEVICEHIGH=. DELDRV défait la dernière session. Ça sert quand on n’a pas le droit de toucher au CONFIG.SYS d’une machine déjà en l’air.

Ce n’est pas dans le produit US. L’arbre le garde parce qu’il est mondial — et parce que ça montre que SYSINIT n’a rien de magique : c’est un chargeur qu’on peut rappeler.

On Japanese DOS (MSKK prefixes, 1987–1991) you can load a driver after the prompt. The file given to ADDDRV is a mini-CONFIG: DEVICE= and DEVICEHIGH= lines. DELDRV undoes the last session. Useful when you cannot touch CONFIG.SYS on a machine that is already up.

Not in the US product. The tree keeps it because it is worldwide — and because it shows SYSINIT is not magic: it is a loader you can call again.

IntermédiaireIntermediate alias D / U / 9

Le parseur (addsub.c) réduit chaque directive à une lettre : D = DEVICE, U = DEVICEHIGH, 9 = DEVICEHIGH SIZE. Puis do_device charge le binaire, device_init envoie la commande 0 (init), on casse l’arène à l’adresse rendue — le même geste que SYSINIT / ExecDev.

Avant tout ça : check_swapper() (MSKK21). Si le swapper Windows (WOA / 386) tourne, on refuse — déplacer la chaîne des devices sous Windows est une recette de plantage. Clavier coupé, INT 23 et 24 attrapés, IRQ masquées pendant l’init (MSKK02).

The parser (addsub.c) folds each directive to a letter: D = DEVICE, U = DEVICEHIGH, 9 = DEVICEHIGH SIZE. Then do_device loads the binary, device_init sends command 0 (init), we break the arena at the returned address — the same gesture as SYSINIT / ExecDev.

Before all that: check_swapper() (MSKK21). If the Windows swapper (WOA / 386) is running, refuse — moving the device chain under Windows is a crash recipe. Keyboard off, INT 23 and 24 trapped, IRQs masked during init (MSKK02).

MIRROR / UNFORMAT — pas Microsoft

DécouverteDiscovery Central Point, 1987–91

FORMAT « sûr » de DOS 5/6 ne détruit plus les données : il réécrit boot, FAT et racine. Pour revenir en arrière, il faut une photo de ce qui était là. MIRROR écrit cette photo (MIRROR.FIL au fond du disque, signature MIRORSAV.FIL dans les derniers secteurs). UNFORMAT (sources dans cps/rebuild/, encore titré « Unformat » par GWD) la relit et recoud.

Copyright Central Point Software, pas Microsoft. DOS 5 a acheté l’outil ; le code le dit encore.

DOS 5/6 “safe” FORMAT no longer wipes data: it rewrites boot, FAT and root. To go back you need a snapshot of what was there. MIRROR writes that picture (MIRROR.FIL at the end of the disk, MIRORSAV.FIL signature in the last sectors). UNFORMAT (sources in cps/rebuild/, still titled “Unformat” by GWD) reads it and stitches.

Copyright Central Point Software, not Microsoft. DOS 5 bought the tool; the code still says so.

IntermédiaireIntermediate /N · /PARTN · FAT 64 Ko

/N : ne pas écrire MIRROR.FIL (implicite sous LOADHIGH). mir_prtn.asm sauve la table de partitions sur disquette. Réseau (IBM et Novell) : refus. FAT plus grande que 64 Ko : « program screws up. Too hard to fix Jim’s kluged code » — on teste sector_count > 128 et on invente une erreur (GWD, 1-May-89).

UNFORMAT a d’abord refusé de tourner sous DOS 5 (1-Jan-89, « Refuses to run under 5.x »). Puis Microsoft l’a embarqué dans DOS 5 : rustines M000–M002 (copyright masqué, sortie propre si pas de fichier Mirror).

/N: do not write MIRROR.FIL (implied under LOADHIGH). mir_prtn.asm saves the partition table to a floppy. Network (IBM and Novell): refuse. FAT larger than 64 KB: “program screws up. Too hard to fix Jim’s kluged code” — test sector_count > 128 and fake an error (GWD, 1-May-89).

UNFORMAT first refused to run under DOS 5 (1-Jan-89). Then Microsoft shipped it in DOS 5: M000–M002 (copyright hidden, clean exit if no Mirror file).

Lecture/écriture via INT 25h/26h (pas INT 13) pour rester au niveau DOS et gérer les grosses partitions 3.31. M009 : MIRORSAV.FIL écrasait des fichiers existants ; la détection de signature dans les derniers secteurs a été corrigée. Delete Tracking est un module à part, volontairement hors de mir_main.asm. I/O via INT 25h/26h (not INT 13) to stay at the DOS level and handle 3.31 huge partitions. M009: MIRORSAV.FIL overwrote existing files; last-sector signature detection was fixed. Delete Tracking is a separate module, deliberately out of mir_main.asm. The build chain (cps/utils/pklite.exe) is not Microsoft’s.

Le client réseau, sans une ligne de source

DécouverteDiscovery cmd/redir/

MS-DOS 6 livre un client LAN (lettres réseau, NET USE). Dans cet arbre : uniquement des binaires. Le makefile copie et compresse. Interlnk (page dédiée) est le cousin « deux PC, un câble » avec source. REDIR est le cousin Ethernet/Token Ring sans.

MS-DOS 6 ships a LAN client (network letters, NET USE). In this tree: binaries only. The makefile copies and compresses. Interlnk (its own page) is the “two PCs, one cable” cousin with source. REDIR is the Ethernet/Token Ring cousin without.

Une lettre réseau, côté noyau, est un CDS dont le flag dit « pas un disque local ». INT 2Fh, même famille que SHARE. Sans source REDIR, le contrat s’arrête là — voir CDS et SHARE.

A network letter, on the kernel side, is a CDS whose flag says “not a local disk”. INT 2Fh, same family as SHARE. With no REDIR source, the contract stops there — see CDS and SHARE.

TechniqueTechnical pourquoi fermé

Le redirecteur vient de LAN Manager / MS-NET, un autre groupe, une autre licence. L’arbre DOS le distribue, il ne le construit pas. On n’ouvre pas les .EXE dans ce guide.

The redirector comes from LAN Manager / MS-NET, another group, another license. The DOS tree ships it, it does not build it. We do not open the .EXEs in this guide.
