cmd/adddrv · redir · cps — et ce qu’on ne raconte pas

Restes de cmd/ Leftovers from cmd/

Après les chapitres, il reste trois tiroirs : un chargeur de drivers japonais, un sac de binaires réseau sans source, et MIRROR/UNFORMAT signés Central Point. Plus QBasic et Setup, volontairement hors livre.

After the chapters, three drawers remain: a Japanese driver loader, a bag of network binaries with no source, and MIRROR/UNFORMAT signed Central Point. Plus QBasic and Setup, left out of the book on purpose.

ADDDRV / DELDRV — MSKK

DécouverteDiscovery DEVICE= après le boot

Sur les builds japonaises (préfixes MSKK 1987–1991), on peut ajouter un driver sans réécrire CONFIG.SYS ni rebooter : ADDDRV fichier parse un mini-config, appelle l’init du device, l’enchaîne sur la chaîne. DELDRV retire. MSKK20 (25-Aug-90) : DEVICEHIGH. MSKK21 : refus si le swapper Windows tourne.

On Japanese builds (MSKK prefixes 1987–1991) you can add a driver without rewriting CONFIG.SYS or rebooting: ADDDRV file parses a mini-config, calls device init, links it into the chain. DELDRV removes it. MSKK20 (25-Aug-90): DEVICEHIGH. MSKK21: refuse if the Windows swapper is running.

IntermédiaireIntermediate device_init · SFT

do_device / load_file / device_init / device_dd : le même contrat que SYSINIT (page CONFIG), joué trop tard. search_sft trouve les handles déjà ouverts sur ce device. Ctrl-Z du fichier config converti en CR/LF (MSKK03). IRQ masquées pendant l’init (MSKK02).

do_device / load_file / device_init / device_dd: the same contract as SYSINIT (CONFIG page), played too late. search_sft finds handles already open on that device. Config-file Ctrl-Z converted to CR/LF (MSKK03). IRQs masked during init (MSKK02).

TechniqueTechnical adddrv.c · deldrv.c

Pas dans le produit US grand public. Conservé parce que l’arbre est mondial. Utile pour comprendre que DEVICE= n’est pas magique : c’est un chargeur qu’on peut rappeler.

REDIR — binaires seuls

DécouverteDiscovery NET, IPX, NETBEUI

cmd/redir/ n’a pas de .c ni de .asm : redir.1xe / redir.2xe, netwksta.*, net.exe, net5.com, netbeui.dos, ipx.obj, tbmi2.com, sstor.sys, dmdrvr.bin, xbios.ovl. Le makefile ne fait que copier et compresser. C’est le client réseau (redirecteur) livré avec DOS, source fermée ici.

cmd/redir/ has no .c or .asm: redir.1xe / redir.2xe, netwksta.*, net.exe, net5.com, netbeui.dos, ipx.obj, tbmi2.com, sstor.sys, dmdrvr.bin, xbios.ovl. The makefile only copies and compresses. This is the network client (redirector) shipped with DOS, closed source here.

IntermédiaireIntermediate .1xe / .2xe

Deux images : DOS 1-ish / DOS 2+ workstation, ou deux tailles. Le noyau parle au redirecteur via INT 2Fh (même famille que SHARE). Sans source, on s’arrête au contrat : une lettre réseau est un CDS dont le flag dit « pas un disque local ».

Two images: DOS 1-ish / DOS 2+ workstation, or two sizes. The kernel talks to the redirector via INT 2Fh (same family as SHARE). With no source we stop at the contract: a network letter is a CDS whose flag says “not a local disk”.

TechniqueTechnical makefile only

Interlnk (page dédiée) est le cousin « câble nul » avec source. REDIR est le cousin LAN sans source. On ne reverse pas les .EXE dans ce guide.

MIRROR et UNFORMAT — Central Point

DécouverteDiscovery cmd/cps/

Copyright 1990–1991 Central Point Software, pas Microsoft. MIRROR écrit une image de la FAT et de la racine (MIRROR.FIL / MIRORSAV.FIL) pour qu’UNFORMAT (module rebuild/, encore appelé « Unformat » dans uf_main.asm) puisse recoller un FORMAT accidentel. FORMAT « safe » de DOS 5/6 s’appuie sur la même idée (page FORMAT).

Copyright 1990–1991 Central Point Software, not Microsoft. MIRROR writes an image of the FAT and root (MIRROR.FIL / MIRORSAV.FIL) so UNFORMAT (module rebuild/, still called “Unformat” in uf_main.asm) can restitch an accidental FORMAT. DOS 5/6 “safe” FORMAT rests on the same idea (FORMAT page).

IntermédiaireIntermediate FAT > 64 Ko

mir_main.asm : « If FAT>64k, program screws up. Too hard to fix Jim’s kluged code, so only added a check for sector_count>128 and fake an error. » (GWD, 1-May-89). /N coupe l’écriture de MIRROR.FIL. Save de la table de partitions sur disquette (mir_prtn.asm). UNFORMAT refusait de tourner sous DOS 5.x (1-Jan-89) — rustines M000–M002 ensuite.

mir_main.asm: “If FAT>64k, program screws up. Too hard to fix Jim’s kluged code, so only added a check for sector_count>128 and fake an error.” (GWD, 1-May-89). /N skips writing MIRROR.FIL. Partition table saved to floppy (mir_prtn.asm). UNFORMAT refused to run under DOS 5.x (1-Jan-89) — M000–M002 later.

TechniqueTechnical utils/pklite.exe

Le dossier cps/utils/ embarque PKLITE, PMAKE, MAKE — la chaîne Central Point, pas celle de Microsoft. Delete Tracking est un module à part, explicitement hors de mir_main.asm.

Ce qu’on ne raconte pas

DécouverteDiscovery QBasic · Setup

cmd/qbasic/ : un autre produit (interpréteur, EDIT, aide). install/ à la racine du dépôt : le Setup. Ni l’un ni l’autre n’est un service du noyau ni un utilitaire de la ligne. CHOICE.COM n’est tout simplement pas là.

cmd/qbasic/: another product (interpreter, EDIT, help). install/ at the tree root: Setup. Neither is a kernel service nor a command-line utility. CHOICE.COM is simply not here.

IntermédiaireIntermediate inventaire cmd/

Tout le reste de cmd/ a une page : COMMAND, les outils disque, les TSR (PRINT, SHARE, FASTOPEN, APPEND, ASSIGN, KEYB, NLSFUNC, SETVER, MODE, DOSKEY, GRAPHICS, GRAFTABL), les filtres, XCOPY/REPLACE/EXPAND, BACKUP/RESTORE, ATTRIB/LABEL/TREE/SYS, HELP, DEBUG, MEM, les rustines, Interlnk, SUBST/JOIN.

Everything else in cmd/ has a page: COMMAND, the disk tools, the TSRs (PRINT, SHARE, FASTOPEN, APPEND, ASSIGN, KEYB, NLSFUNC, SETVER, MODE, DOSKEY, GRAPHICS, GRAFTABL), the filters, XCOPY/REPLACE/EXPAND, BACKUP/RESTORE, ATTRIB/LABEL/TREE/SYS, HELP, DEBUG, MEM, the patches, Interlnk, SUBST/JOIN.

TechniqueTechnical fin de la saga cmd/

Le noyau (dos/, bios/, boot/, dev/) et DOSSHELL (dosshell/) sont déjà couverts. c6ers/ est la bibliothèque C des utilitaires, pas un chapitre. On a épuisé cmd/.

The kernel (dos/, bios/, boot/, dev/) and DOSSHELL (dosshell/) are already covered. c6ers/ is the utilities’ C library, not a chapter. cmd/ is exhausted.
