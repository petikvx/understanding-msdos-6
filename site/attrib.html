cmd/attrib · label · tree · sys

ATTRIB · LABEL · TREE · SYS

Quatre petits outils qui parlent au répertoire et au secteur 0. Attributs R/S/H/A, nom de volume, dessin de l’arbre, copie d’IO.SYS/MSDOS.SYS/COMMAND.COM aux bons clusters.

Four small tools that talk to the directory and to sector 0. R/S/H/A attributes, volume label, a drawing of the tree, copy of IO.SYS/MSDOS.SYS/COMMAND.COM onto the right clusters.

ATTRIB +R -H /S

DécouverteDiscovery le 12e octet

Chaque entrée répertoire a un octet d’attributs (page FAT). ATTRIB est le tournevis : +R lecture seule, +H caché, +S système, +A archive. /S descend. Sans signe : affiche l’état.

Each directory entry has an attribute byte (FAT page). ATTRIB is the screwdriver: +R read-only, +H hidden, +S system, +A archive. /S descends. No sign: print the state.

IntermédiaireIntermediate ancienne syntaxe EA

L’en-tête de attrib.c montre deux syntaxes. L’ancienne (DOS 4) acceptait des attributs étendus [id]|[id=value]. La nouvelle : {+,-}{R,S,A,H} seulement. Les EA OS/2 n’ont pas survécu dans l’usage DOS 6, le code de message est encore là.

The header of attrib.c shows two syntaxes. The old one (DOS 4) accepted extended attributes [id]|[id=value]. The new one: {+,-}{R,S,A,H} only. OS/2 EAs did not survive in DOS 6 use; the message code is still there.

TechniqueTechnical AH=43h

INT 21h AH=43h (chmod) — pas d’écriture directe de l’entrée. SHARE et le bit read-only du SFT restent cohérents. XCOPY /M et BACKUP /M consomment le même bit A.

LABEL

DécouverteDiscovery 11 caractères, entrée 08h

Le nom de volume est une entrée répertoire d’attribut Volume (08h), plus une copie dans le BPB étendu. LABEL sans argument affiche, demande, détruit l’ancienne, crée la nouvelle. VOL (interne COMMAND) ne fait que lire.

The volume name is a directory entry with the Volume attribute (08h), plus a copy in the extended BPB. LABEL with no argument displays, prompts, deletes the old one, creates the new. VOL (COMMAND internal) only reads.

IntermédiaireIntermediate Ctrl-C et atexit

label.c pose INT 23h et atexit(ExitLabel) : si on casse au milieu, on ne laisse pas deux labels. Vérifie la version DOS comme presque tous les utilitaires C de cette génération.

label.c installs INT 23h and atexit(ExitLabel): if you break in the middle, you do not leave two labels. Checks the DOS version like almost every C utility of that generation.

TechniqueTechnical FORMAT aussi

cmd/format/forlabel.asm écrit le même type d’entrée après un format. Deux chemins, une structure — page FORMAT.

TREE

DécouverteDiscovery /F /A

Dessine l’arbre à partir d’un dossier (racine par défaut). /F liste aussi les fichiers. /A : ASCII +-- au lieu des caractères graphiques OEM (qui exigent GRAFTABL en mode graphique CGA).

Draws the tree from a folder (root by default). /F also lists files. /A: ASCII +-- instead of OEM graphic characters (which need GRAFTABL in CGA graphics mode).

IntermédiaireIntermediate errorlevel 0/1/2/3

0 ok, 1 I/O, 2 mauvaise version DOS, 3 Ctrl-Break. Ne change ni le drive courant ni le répertoire — FindFirst attribut directory, puis récursion.

0 ok, 1 I/O, 2 bad DOS version, 3 Ctrl-Break. Changes neither current drive nor directory — FindFirst with directory attribute, then recursion.

TechniqueTechnical tree.asm

Assembleur, stdout seulement. Les glyphes ├── / └── sont des octets CP437 ; redirigés dans un fichier ils dépendent de la page de codes du TYPE ultérieur (page NLS).

SYS C:

DécouverteDiscovery rendre un disque bootable

FORMAT /S le fait à la naissance. SYS le fait après coup : copie IO.SYS, MSDOS.SYS, COMMAND.COM, réécrit le secteur boot. Les deux premiers doivent occuper les premiers clusters contigus — le chargeur à 7C00h ne sait pas encore marcher une FAT fragmentée (page Boot).

FORMAT /S does it at birth. SYS does it afterwards: copies IO.SYS, MSDOS.SYS, COMMAND.COM, rewrites the boot sector. The first two must occupy the first contiguous clusters — the loader at 7C00h cannot yet walk a fragmented FAT (Boot page).

IntermédiaireIntermediate déménager un cluster

Si les premiers clusters sont pris, SYS les libère : lit l’entrée, trouve un trou, déplace le cluster, met à jour FAT et répertoire. C06 (29-Mar-90) : le buffer des fichiers système était écrasé quand le cluster à bouger dépassait 4 Ko. M005–M008 : gros numéros de clusters, test EOF, flush FAT #2 qui écrasait la racine, CDS à jour après déplacement d’un sous-répertoire.

If the first clusters are taken, SYS frees them: read the entry, find a hole, move the cluster, update FAT and directory. C06 (29-Mar-90): the system-file buffer was overwritten when the cluster to move was larger than 4 KB. M005–M008: large cluster numbers, EOF test, FAT #2 flush that overwrote the root, CDS updated after moving a subdirectory.

SYS réimplémente une mini-FAT (comme CHKDSK et RECOVER) au lieu d’appeler ALLOCATE. Il doit garantir la contiguïté, ce que le noyau ne promet pas.

SYS reimplements a mini-FAT (like CHKDSK and RECOVER) instead of calling ALLOCATE. It must guarantee contiguity, which the kernel does not promise.
