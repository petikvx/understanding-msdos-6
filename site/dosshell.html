DOSSHELL

Le gestionnaire de fichiers graphique de DOS 5/6. Il ne remplace pas COMMAND : il lui injecte des lignes (INT 2Fh déjà vu dans tcode.asm) et permute des programmes en les écrivant sur disque (WOA — Windows on MS-DOS? plutôt « swapper » maison).

The DOS 5/6 graphical file manager. It does not replace COMMAND: it injects lines (INT 2Fh already seen in tcode.asm) and swaps programs by writing them to disk (WOA files — an in-house swapper).

Two panes, tree, associations. Behind them: the same FindFirst / COPY / ATTR as COMMAND. dosintf.c is the bridge to INT 21h.

The UI comes from a “Character Oriented Windows” lib (lib/cow3.lib, cwindows.h). Grabbers grbs/*.grb save the graphics screen on swap.

Le swapper

DécouverteDiscovery taskman.c · Alt+Tab

Ce n’est pas du vrai multitâche. On gèle FOO.COM, on écrit son image (et l’écran) sur disque, on lance BAR.COM. Revenir = relire. XMS accélère (woaxms.asm).

This is not real multitasking. FOO.COM is frozen, its image (and the screen) written to disk, BAR.COM launched. Coming back = reread. XMS speeds it up (woaxms.asm).

IntermédiaireIntermediate woa*.asm

Une douzaine de modules : arènes (woaarena.inc), souris, clavier, erreurs, init. Le swapper est un petit DOS à lui tout seul, plus gros que PRINT.

A dozen modules: arenas (woaarena.inc), mouse, keyboard, errors, init. The swapper is a little DOS of its own, larger than PRINT.

TechniqueTechnical loader/shell.asm

Un chargeur minuscule reste résident ; le gros SHELL.EXE se fait overlay / swap. Même idée que COMMAND résident/transient, en beaucoup plus lourd.

Parler à COMMAND

DécouverteDiscovery mult_shell_get

Avant READBAT, COMMAND demande : « SHELL, tu as une ligne ? » DOSSHELL répond oui et pousse DIR /W dans COMBUF. L’utilisateur croit avoir cliqué ; c’est un batch fantôme.

Before READBAT, COMMAND asks: “SHELL, do you have a line?” DOSSHELL says yes and pushes DIR /W into COMBUF. The user thinks they clicked; it is a ghost batch line.

IntermédiaireIntermediate launch.c

Lancer un .EXE : soit INT 2Fh + COMMAND, soit $EXEC direct. Le swapper doit alors geler le shell lui-même (assez de RAM ?).

Launching an .EXE: either INT 2Fh + COMMAND, or $EXEC directly. The swapper must then freeze the shell itself (enough RAM?).

TechniqueTechnical winidle.asm

Sous Windows, le shell se tient tranquille (idle). Même politesse que SMARTDRV indosbox.asm et MEM wintest.asm.
