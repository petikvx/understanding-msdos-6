cmd/graphics · cmd/graftabl — OASIS / INT 1Fh

GRAPHICS · GRAFTABL

Deux TSR vidéo. GRAPHICS vole Print Screen pour envoyer le mode graphique à l’imprimante (profils imprimante). GRAFTABL pose 1 Ko de glyphes 128–255 sur INT 1Fh, sans quoi le CGA en SCREEN 1 affiche des poubelles à la place des accentués.

Two video TSRs. GRAPHICS steals Print Screen to send graphics mode to the printer (printer profiles). GRAFTABL plants 1 KB of glyphs 128–255 on INT 1Fh; without it a CGA in SCREEN 1 shows garbage instead of accented letters.

Shift-PrtSc en CGA

DécouverteDiscovery INT 5

Le BIOS n’imprime que le mode texte. GRAPHICS remplace INT 5 : lit la mémoire écran, tramage N&B ou couleur selon le profil (.PRO chargé à l’install), parle au LPT. Sans lui, PrtSc en 320×200 donne une page blanche ou n’importe quoi.

The BIOS only prints text mode. GRAPHICS replaces INT 5: reads screen memory, dithers B&W or colour according to the profile (.PRO loaded at install), talks to LPT. Without it, PrtSc in 320×200 is a blank page or worse.

IntermédiaireIntermediate GRINST · profils

Install dans grinst.asm. Chargeurs grload*.asm lisent GRAPHICS.PRO. Impression N&B grbwprt.asm, couleur grcolprt.asm, motifs grpattrn.asm. A002 : libérer l’environnement avant de rester résident (même geste que beaucoup de TSR DOS 4).

Install in grinst.asm. Loaders grload*.asm read GRAPHICS.PRO. B&W print grbwprt.asm, colour grcolprt.asm, patterns grpattrn.asm. A002: free the environment before going resident (same gesture as many DOS 4 TSRs).

GRAFTABL 850

DécouverteDiscovery INT 1Fh → 8×128

En texte (SCREEN 0), le CGA a les 256 caractères. En graphique (SCREEN 1), seuls 0–127 sont dans le ROM. 128–255 sont dessinés d’après la table pointée par INT 1Fh, souvent 0000:0000. GRAFTABL y met 1024 octets (8 lignes × 128) et reste.

In text (SCREEN 0), the CGA has all 256 characters. In graphics (SCREEN 1), only 0–127 live in ROM. 128–255 are drawn from the table pointed to by INT 1Fh, often 0000:0000. GRAFTABL puts 1024 bytes there (8 rows × 128) and stays.

IntermédiaireIntermediate 437 850 852 860 863 865

Une table par page : USA, multilingual, Latin II, Portuguese, Canadian French, Nordic. /STATUS interroge le multiplex B0h pour savoir laquelle est chargée — on peut redéfinir sans empiler un second Ko.

One table per page: USA, multilingual, Latin II, Portuguese, Canadian French, Nordic. /STATUS asks multiplex B0h which one is loaded — you can redefine without stacking a second kilobyte.

Le choc ANSI

DécouverteDiscovery M001 30-Jan-91

ANSI.SYS change de mode vidéo (y compris via une séquence « alt-prt-sc select »). Ça réinstalle l’INT 5 du BIOS — GRAPHICS disparaît. Correctif : GRAPHICS crochète aussi INT 10h et remet son INT 5 quand ANSI a parlé.

ANSI.SYS changes video mode (including via an “alt-prt-sc select” sequence). That reinstalls the BIOS INT 5 — GRAPHICS vanishes. Fix: GRAPHICS also hooks INT 10h and puts its INT 5 back after ANSI has spoken.

IntermédiaireIntermediate MODE CON

MODE 40/80 et GRAFTABL se marchent moins dessus (GRAFTABL ne dépend que d’INT 1Fh). GRAPHICS + MODE + ANSI : trois habitants de la même carte, d’où M001.

MODE 40/80 and GRAFTABL step on each other less (GRAFTABL only depends on INT 1Fh). GRAPHICS + MODE + ANSI: three tenants of the same card, hence M001.

TechniqueTechnical grint2fh.asm

« New int 10 handler to trap alt-prt-sc select calls made by ANSI.SYS. For these calls, we need to reinstall our int 5 handler again. » — NSM, 30-Jan-91.
